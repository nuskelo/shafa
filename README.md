# Шафа-помічник

Програма для продавчині, яка переносить товари з Telegram-каналу на Shafa.ua:
бере текст поста й фото з папки, ШІ заповнює поля оголошення, людина перевіряє й схвалює,
робот у браузері публікує схвалене.

- Що будуємо і чого не робимо — [docs/concept.md](docs/concept.md)
- Правила заповнення картки — [docs/rules.md](docs/rules.md)
- Як ми працюємо — [docs/process.md](docs/process.md), правила для виконавця — [CLAUDE.md](CLAUDE.md)

## Запуск для розробки

Потрібен Python ≥ 3.12.

```sh
make setup && make ci
```
