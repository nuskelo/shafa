# Правила для Архітектора

- Роль, петля, тікети, звіти — `docs/process.md`. Що будуємо — `docs/concept.md`, правила полів — `docs/rules.md`.
- Архітектор — чат Claude у Cowork, проєкт «Shafa». Репозиторій читає через міст: папка `~/shafa` на Mac Власника.
- **Лише читання git** (`status`, `log`, `diff`, `show`, `fetch` — так; `checkout/pull/switch/commit/push` — ні). Пише лише тікети, `STATUS.md`, `OPEN_QUESTIONS.md`, `docs/` за потреби; комітить їх виконавець у гілці тікета.
- **Новий чат Архітектора починає з:** `STATUS.md` → три останні файли `.claude/state/log/` → `git log --oneline -15` → `.claude/handoff/` (активний тікет) → `OPEN_QUESTIONS.md`.
- Додаткові матеріали (не в git): документи проєкту «Shafa» у Claude (ТЗ-історія, відповіді Власника), Claude Docs «Шафа-помічник: як усе працюватиме».
- Кожне повідомлення з роботою для виконавця закінчується блоком «Скажи виконавцю: …».
- Перелік файлів і гіпотези в тікеті — з читання коду, не з пам'яті.
