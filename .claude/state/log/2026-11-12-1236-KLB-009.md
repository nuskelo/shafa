# KLB-009 — вкладка «Клубок» на екрані
- Перемикач «Шафа | Клубок»; вкладки Клубку: На перевірку («лише Клубок»), У черзі (порядок і хвиля, «Перерахувати чергу»), Треба рішення, Виставлено, Не піде (за причиною).
- Картка `/klubok/item/N`: «Як буде на Клубку» з `fields.ad`; «Схвалити для Клубку» / «Не виставляти» / «Далі →»; дубль; «перевірте, чи опубліковано» — номер → `queue.confirm` або `queue.retry` → у чергу.
- Панель робота Клубку: Старт (`--limit` = залишок доби), Пауза/Стоп через `sessions.command`, Увійти, Перечитати оголошення; спільний замок з Шафою. TD-078.
