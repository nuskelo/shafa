# ROBOT-020 · 25.11 · Telegram не відповів на перевірку каналу
- Раніше «невідомо» (429, таймаут, 5xx) = публікуємо як завжди (сесії 69, 70: 14 пар наосліп). Тепер `Run._channel`: чекаємо `retry_after`+5 с чи 30/60 с, ≤ 3 перевірок на Картку.
- Усе ще невідомо → Картка `approved`, у звіті «Відкладено…»; за сесію ≤ 20 хв очікування, далі `Stop("telegram_busy")`. Панель: стадія `wait_channel`; Пауза/Стоп працюють (`_countdown`).
- Клубок живої перевірки каналу не має — без змін. Тести: 8 червоніють без фіксу.
