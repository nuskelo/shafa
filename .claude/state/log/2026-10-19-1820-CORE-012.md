# CORE-012 · 19.10.2026
Живий dry-fill 3650 показав обов'язковий блок «Виберіть размер *» у рукавичок, якого знімок не мав (`sizes: {}`, відповідь форми `sizeGroups` порожня). Блок вписано в знімок для «Рукавички» за скриншотом (`size_block`); `sync.read_size_block` читає його з форми при наступному `--sync-catalog`.
Розмір аксесуара береться з тексту, не від ШІ (`rules.letter_sizes` лише поруч зі словом «розмір», `ai.accessory_sizes`): вживане до двох, нове — одна й жовте, немає — робот ставить «Інший». `plan.required_gaps`: обов'язкове поле без кроку → `PlanError` (публікація — «Проблема» до кліку, dry-fill — рядок у журнал).
Пропущена частина попередньої сесії: код був у робочому дереві без комітів — перевірено, розбито на коміти за пунктами тікета. `RULES_VERSION` не піднято (рішення за Архітектором, див. handoff). TD-048.
