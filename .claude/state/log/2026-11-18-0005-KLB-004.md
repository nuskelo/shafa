# KLB-004 — «Обновить все» на Клубку робить робот
- Фаза 0: «Обновить все» чіпає лише прострочені (10.11: «(1785)» з 1787), у кожного свій термін = мить оновлення + 7 діб; безкоштовне; живого знімка після 17.11 ще немає.
- `robot --klubok-renew [--human-click]`, початок сесії публікації, щоденний запуск о `SHAFA_KLUBOK_RENEW_AT` (20:00): посилання «Обновить все (N)» є → один GET `/renew/all` за `RenewTicket`, не частіше раз на добу; перевірка — ≥ 95 % прострочених зсунулись і активних ≥ 90 %.
- Панель «Обновить все: наступне / оновлено / прострочено», тривога Власнику > 12 год; `klubok.renew` / `klubok.renew_failed`. Перший живий запуск — 24.11 при Владі.
