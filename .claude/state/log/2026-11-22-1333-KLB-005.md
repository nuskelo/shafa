# KLB-005 — «Схоже, продано»: зняття з Клубку після «Так»
- Виявлення без мережі (`klubok/sold.py`, у `refresh`): пост виставленої пари зник (`post_checks.gone_at`) → `sold_asked`; її оголошення з надійним постом — теж; продане руками — тихо `sold`.
- Екран: блок «Схоже, продано (N)» над «Проблемами» Клубку; «Так» → чекає робота, «Ні» → не питати.
- Робот (`robot/klubok_marksold.py`, `--klubok-marksold`, початок сесії публікації): `MarkSoldTicket` — один GET на id; перевірка `type=2` `sold: true` → `removed`, інакше гучно й питання знову.
- Перший живий — лише `--human-click --limit 1` при Владі.
