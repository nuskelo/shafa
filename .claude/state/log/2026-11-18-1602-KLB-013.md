# KLB-013 — прострочені оголошення Клубку у вкладці «Обновить»
- Факт (живий прогін 18.11): `get-items` `type=1` — вкладка «Обновить»; прострочене зникає з `type=0` (17.11: 1780 з 1798) → знімок давав `klubok_snapshot_drop`, а малі групи ставали `sold = 1`.
- Знімок = `type=0` ∪ `type=1`, прострочене `sold = 0`; «Обновить все» — спершу посилання, потім знімок (падіння знімка «до» не зупиняє); перевірка — вкладка «Обновить» після ≤ 5 % і посилання зникло.
- Сесія публікації оновлює до знімка; текст зупинки «Схоже, оголошення прострочені (N)»; підставний Клубок з вкладками й `expire(N)`.
