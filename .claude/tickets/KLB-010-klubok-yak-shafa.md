## Що Архітектор побачив на живому екрані (12.11, 5c79e66; лише перегляд)
- **F1 Шапка Клубку ламається:** на 1440 px «Вийти» переїжджає на другий рядок (у Шафи — ні). Вкладок у Клубку більше (6 + «Ще»).
- **F2 Назви вкладок різні для того самого:** Шафа «Схвалені / Проблеми / Опубліковані / Архів (у «Ще»)», Клубок «У черзі / Треба рішення / Виставлено / Не піде». → Клубок: **«На перевірку · Схвалені · Проблеми · Опубліковані · Ще ▸ Архів (не піде)»** — ті самі слова, порядок, кількість; «У черзі» = «Схвалені» (з номером місця й хвилею, як місце в Шафі).
- **F3 «Ще 192 схвалених пар не перераховано» + кнопка «Перерахувати чергу», лічильник «33 +192».** Людина не має перераховувати чергу. Черга Клубку **завжди актуальна**: `sync` після імпорту, схвалення, «Не виставляти», зміни налаштувань Клубку, знімка, «Обновить»/кінця сесії і на старті програми (не в GET). Один лічильник.
- **F4 Панель робота Клубку інша, ніж у Шафи.** Шафа: «Сьогодні опублікує N Карток · ≈ хв», плитки груп, «Старт», «Пробно заповнити…», «Останній запуск…». → Клубок тим самим каркасом: «Сьогодні виставить N пар · ≈ хв», плитки «Хвиля 1 / Хвиля 2 / Схвалені», «Старт»; «Перечитати мої оголошення» й «Увійти в Клубок» — другорядні (як «Пробно заповнити» у Шафи), «Останній запуск: … — виставлено N · Подробиці сесії».
- **F5 Картка Клубку інша, ніж у Шафи:** у Шафи — жовта плашка зверху + «→ Щоб схвалити: …», фото ліворуч, поля праворуч одразу на першому екрані, внизу «Попросити ШІ заповнити заново · Ще · Не публікувати (в Архів) · Зберегти · Схвалити і далі», угорі статуси «Робот · ШІ · Бот · Сайт». У Клубку блок «Як буде на Клубку» на всю ширину зсуває фото й поля вниз; внизу інші кнопки; угорі лише «Робот Клубку». → **Той самий каркас Шафи**; «Як буде на Клубку» — компактний блок у правій колонці над полями (або згорнутий «▸ Як буде на Клубку» з короткою зведеною стрічкою); кнопки — ті самі назви: «Попросити ШІ заповнити заново · Ще · Не виставляти (в Архів) · Зберегти · **Схвалити і далі**»; статуси вгорі — як у Шафи.
- **F6 Суперечність:** «Не піде на Клубок: немає категорії» і нижче «Клубок: піде після схвалення»; текст причини повторено двічі. Одна причина, одним реченням, і кнопка «Схвалити» неактивна з поясненням (як у Шафи).
- **F7 Ціна:** на Картці «лише Клубок» поле «Ціна на Шафі, грн 750 (у пості 650 → +15 %)», а на Клубок іде ціна з поста. → Для «лише Клубок» — «Ціна на Клубку, грн» (з поста, можна правити, саме вона йде на Клубок); для Картки Шафи на вкладці Клубку — «Ціна на Клубку: 650 (з поста)».
- **F8 Телефон:** верхня смуга Картки Клубку — три рядки (назад/лічильник, Назад/Далі, статус). Як у Шафи на тій самій ширині.
- **F9 Сторінка 404** («Такої сторінки немає») — без шапки й відступів, текст прилип до краю (і в Шафи). → звичайна сторінка з шапкою.
- **F10 Хвилі (логіка):** у хвилю 1 потрапили **рукавиці** (пост 3800, «зимові рукавиці» → «зима») і **тапочки на хутрі** (4045, 4145 → «зима» через «хутр»). `klubok/waves.py`: спершу домашнє / одяг / аксесуари (рукавиці, шапки, шарфи), потім зима; виправлені класи — для вже записаних `klubok_waves` (одноразово, з рядком у журналі). Тапочки — хвиля 4, рукавиці/одяг — не імпортуються.
- **F11 Дублі без бренду надто широкі:** «Новий шкіряний рюкзак» ≈ «Шкіряна сумка в ідеальному стані», «Шкіряна сумка в новому стані» ≈ «Шкіряна сумка Італія…». Для Картки **без бренду**: дубль лише при тому самому підтипі (рюкзак / сумка / гаманець / клатч / черевики / чоботи / кросівки…) **і** ціні ±25 % **і** схожій назві; інакше — не дубль. Вже записані такі «Проблеми» — перерахувати (з бренду нічого не змінюється).
