# CORE-016 — сезон: «термо» = мембрана, а не зима

**Вага:** мала (~20–30 хв). **Знайдено 21.10 (Влад):** «Термо кросівки Keen» (6566) отримали «Зима». Так само всі 25 «термо кросівок» у базі.
**Аналоги:** `rules.season` (`rules.py` ~190–240, `WINTER`, `DEMI`, `_WINTER`-шаблон, `_SEASON_NAMED`), `ai.check_season`, `prompts/blank.md` (рядок **season**), тести QA-001 / CORE-007 на сезон.

## Навіщо
Вікторія пише «термо» про мембранне взуття. Зимові пари вона сама називає «Зимові термо черевики» або пише «хутро», «утеплені», «фліс». Зараз код ставить «Зима» на будь-яке «термо», і ШІ це не може змінити.

## Нове правило (вирішує код, як зараз)
| Що в тексті | Сезон |
|---|---|
| «зимові», хутро (не «без хутра»), «утепл…», фліс, уги, дутики | **Зима** (як зараз) |
| «термо» + кросівки / кеди (тип з тексту або тип Картки) без ознак зими | **Демісезон** |
| «термо» + черевики / чоботи / сапожки / ботильйони без ознак зими | **Демісезон, Зима** (обидва) |
| «термо» з іншим типом або тип невідомий | **Демісезон, Зима** |
| сезон названо прямо («демісезон», «літо»…) | як зараз |

- «Термочеревики» (злито), «термо-кросівки», «ккросівки» (опечатка 6939) — розпізнавати.
- Суперечність (у тексті «літо» і «зимові») — жовте, як зараз.
- Мембрана без «термо» — Демісезон, як зараз.
- Якщо для розділу Шафи нема «Демісезон» чи «Зима» у знімку — лише те, що є (`check_values`).
- `prompts/blank.md`: виправити рядок **season** під нове правило (ШІ не має писати «термо → зима»).

## Наявні Картки
- `published` — не чіпати (Шафу не редагуємо).
- `new`, `review`, `approved`, `problem` — сезон перерахувати **без ШІ** (є готове: `fill.recheck` / `recalc`, CORE-015). `approved`, у яких сезон змінився → «На перевірку» з жовтою приміткою «сезон змінено правилом: було Зима → стало …».
- RULES_VERSION **не піднімати**, якщо перерахунок можна зробити без цього (піднімання = усі Картки `stale_rules`). Якщо без нього ніяк — зупинись і опиши в handoff, не роби.
- Команда для Власника, щоб запустити перерахунок (наявна `fill --recheck` чи нова опція) — у handoff, з `--dry-run`, що покаже «змінилось N: пости …».

## Заборони
`robot/guard.py`, `robot/browser.py`, `db.py` — не змінювати. Справжніх запитів до ШІ — ні. Тести лише в `tmp_path`. Живу Шафу, канал, сайт, `.env` — не чіпати.

## Тести (на справжніх перших рядках постів)
- «Термо кросівки Keen в ідеальному стані…» → Демісезон.
- «Термо кросівки Lowa з мембраною gore-tex…» → Демісезон.
- «Термо ккросівки VADO…» → Демісезон.
- «Шкіряні термо черевики Meindl з мембраною gore-tex…» → Демісезон, Зима.
- «Зимові термо черевики Merrell…» → Зима. «Зимові термочеревики Viking…» → Зима.
- «Термо черевики Converse… хутро…» → Зима; «без хутра» → не Зима.
- «Нові термо черевики Peter Storm. В наявності декілька розмірів.» → Демісезон, Зима.
- Перерахунок: `published` не змінився; `approved` зі зміною → `review` з приміткою; без зміни — лишився `approved`.
