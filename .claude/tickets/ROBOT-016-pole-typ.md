# ROBOT-016 — поле «Тип» (Челсі, Берці) не заповнюється: зібрати розмітку і виправити вибір

**Вага:** мала–середня (30–60 хв). **Модель:** Sonnet · High.
**Аналоги:** `form.optional` (~201), `form.pick_values` (~284), `save_markup` (ROBOT-004, для обов'язкових полів), ROBOT-009.

## Що сталось
Необов'язкове поле «Тип» не заповнюється — 8 разів за 21–23.10 (rehearse 22.10: 1, 23.10: 5; публікація: 2). Приклад нотатки:
`Необов'язкове поле «Тип» не заповнено: на формі не знайдено Берці (поле «Тип»; вибрано: Додайте заголовок(до +11%); у списку (0): порожньо`
У знімку `shafa-catalog.json` для «Жіночий одяг / Взуття / Черевики» характеристика 6 «Тип» має варіанти «Берці», «Челсі» — тобто поле існує, а робот бачить порожній список і «чип» з текстом підказки Шафи «Додайте заголовок (до +11%)». Схоже, робот бере **не той елемент** (блок-підказку якості оголошення поруч), а не саме поле «Тип». Оголошення публікуються без «Типу» — не критично, але Шафа, ймовірно, гірше показує такі оголошення.

## Що зробити
1. **Діагностика (обов'язково):** при невдачі необов'язкового поля зберігати розмітку блоку і скриншот так само, як для обов'язкових (`save_markup`, суфікс `тип-поля`), не частіше одного разу за поле за сесію. Шлях — у нотатці.
2. **Фаза 0 за кодом:** знайти, чому `_find("Тип")` / віджет повертає блок з «Додайте заголовок (до +X%)». Перевірити гіпотези нижче на розмітці з тестів/підставної Шафи (відтворити схожу структуру: підказка якості з «Тип» у тексті поруч з полем).
3. **Виправлення:** «чипи», текст яких схожий на підказку Шафи (`Додайте …`, `(до +N%)`), — не чипи і не поле; шукати поле «Тип» точніше (підпис рівно «Тип», не підрядок). Якщо список після відкриття порожній — один раз закрити й відкрити знову (як для інших списків).
4. Наслідок для решти полів: та сама підказка могла заважати й «Матеріалу» (1 випадок) — перевір тестом.

## Гіпотези (Фаза 0)
- HYP-1: `_find` шукає підпис «Тип» як підрядок і чіпляється за блок підказки (у тексті підказки є «тип» / «Додайте тип…»).
- HYP-2: правильне поле знайдено, але список ліниво вантажиться після вибору розділу і в момент відкриття порожній.
- HYP-3: «вибрано: Додайте заголовок…» — це не чип, а текст сусіднього блоку, який `chips()` захоплює через загальний селектор.

## Заборонено
`robot/guard.py`, `robot/browser.py`, `db.py`, `rules.py`, `shafa-catalog.json` — не змінювати. Жодних нових кліків поза полем «Тип» / списком цього поля. Не публікувати, живу Шафу не відкривати, пілот не чіпати. RULES_VERSION не піднімати.

## Тести (tmp_path, підставна Шафа / фейкова розмітка)
- блок підказки «Додайте заголовок (до +11%)» поруч — робот вибирає «Челсі» у справжньому полі «Тип»;
- підказка не вважається чипом;
- порожній список при першому відкритті → друге відкриття → вибрано;
- невдача необов'язкового поля → файл розмітки + скриншот, один раз за сесію.
