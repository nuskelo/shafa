# WIN-001 · Програма для її ноутбука з Windows: встановлення, ярлик, налаштування

**Вага:** критична (секрети на чужому комп'ютері, встановлення, живий акаунт). Фаза 0 повністю, **зупинка до коду**.
**Автор:** Архітектор · 15.10.2026
**Гілка:** `feature/WIN-001-windows` від `origin/main` після `git fetch` (після мержу PR #11).
**Перший коміт:** цей тікет і `.claude/state/STATUS.md` від Архітектора.

## Навіщо
Усе працює на Mac Власника. Продавчиня працюватиме на своєму ноутбуці з Windows: один ярлик на робочому столі → відкривається екран перевірки, у фоні працюють бот і (за кнопкою) робот. Власник ставить програму **наживо**, налаштовує секрети, вхід на Шафу й AnyDesk; далі оновлює й допомагає віддалено. Без автозапуску з Windows (рішення 06.10) — лише ярлик.

## Фаза 0 — повністю, зупинка до коду
- HYP-1: **Спосіб доставки.** Порівняй: (а) вбудований Python (python.org embeddable 3.12) + наш пакет і залежності в одній теці + ярлик; (б) PyInstaller/подібне в один exe; (в) офіційний інсталятор Python 3.12 + venv скриптом. Критерії: чи потрібні права адміністратора, розмір, як працює Playwright із встановленим Chrome, як **оновлювати** (Власник через AnyDesk: замінити теку / один скрипт), антивірус Windows Defender (exe без підпису часто блокується), відсутність консольних вікон. Рекомендація.
- HYP-2: **Збірка.** Де збирати пакет для Windows: на GitHub Actions (windows-latest) як артефакт PR/релізу — потрібна зміна `.github/` (дозвіл дам) — чи на Mac. Залежності закріплені з хешами (TD-005: lock-файл / constraints).
- HYP-3: **Шляхи на Windows.** Тека даних (база, мініатюри, профіль робота, журнали, `.env`) — `%LOCALAPPDATA%\shafa\`. Головна папка — `Робочий стіл\Шафа` (OQ-001: підтвердити з Власником), тека «Опубліковано» в ній. Кирилиця в шляхах, OneDrive-перенаправлення «Робочого столу» (часто на Windows!) — перевір.
- HYP-4: **Запуск без вікон:** ярлик → одна команда, що піднімає екран (браузер відкривається сам), бота (якщо налаштований) як окремий процес без консолі; повторний клік на ярлик не запускає друге — відкриває той самий екран. Закриття браузера не вбиває бота; «Вийти» на екрані — гасить усе.
- HYP-5: **Секрети на її ноутбуці:** `ANTHROPIC_API_KEY` (окремий ключ для неї, не ключ Власника — створити в Console), `TELEGRAM_BOT_TOKEN` (окремий **робочий** бот, не тестовий), канал, чати. Як Власник вводить їх наживо, щоб вони не світились на екрані й не потрапили в журнали — скрипт налаштування з прихованим введенням. Права доступу до `.env` на Windows (лише її користувач).
Після Фази 0 зупинись: «WIN-001 фаза 0 готова».

## Що зробити (план; уточнимо після Фази 0)
1. Скрипт/команда збирання пакета для Windows + закріплені залежності (TD-005).
2. Запускач: ярлик «Шафа-помічник» з іконкою; екран + бот без консолей; один екземпляр.
3. **Майстер першого налаштування** (запускає Власник наживо): головна папка, секрети (приховано), перевірка ключа ШІ (1 безкоштовний запит на перелік моделей, без витрат), перевірка бота й каналу/групи, `robot --login` для входу на Шафу (вона вводить пароль сама).
4. **Сторінка «Налаштування»** на екрані (без секретів): ліміт публікацій на добу (30), ліміт ШІ на добу ($3), «через 7 днів», головна папка, прапорець видалення «Опубліковано» через 3 дні (типово вимкнений). OQ-006.
5. Кнопка **«Завантажити експорт каналу»** на екрані (TD-021): вибрати `result.json` → пости в базу.
6. Оновлення: один скрипт/кнопка для Власника, що ставить нову версію, не чіпаючи даних (база, профіль, `.env`).
7. `docs/install-windows.md` — **покрокова інструкція для Власника на день встановлення** простими словами: що взяти з собою, по одній дії, з тим, що має вийти; AnyDesk (встановлення, пароль для доступу без підтвердження — лише якщо Продавчиня згодна).
8. Тести: шляхи Windows/кирилиця/OneDrive (у `windows-tests`), один екземпляр, майстер без мережі (підставні відповіді), секрети не потрапляють у журнали.
9. `CLAUDE.md`, TD (закрити TD-005, TD-021; TD-010/019 — після встановлення), журнал — останнім комітом.

## Заборонено
Секрети в репозиторії, артефактах збірки, журналах. Автозапуск з Windows. Будь-які дії на її ноутбуці — це робить Власник наживо. Пуш у `main`, мерж, `push --force`, `reset --hard`.
