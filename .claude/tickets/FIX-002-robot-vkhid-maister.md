# FIX-002 · Робот «не увійшов», хоча вхід є + майстер на Windows + рукавички

> Архітектор, 17.10.2026. **Терміново — блокує першу публікацію в Продавчині.** Гілка `fix/FIX-002-robot-vkhid` від свіжого `origin/main` (SITE-001 відкласти: закомітити й запушити поточне в його гілку). Першим комітом — цей тікет і STATUS.md. Без Фази 0.

## Що сталося в неї (Windows, слабкий ноут, пакет 7d77d3e, дані в `D:\shafa` через `SHAFA_DATA_DIR`)
1. «Старт» → через **4 с** «Робот не увійшов на Шафу» (сесії 1 і 2, `stop_code=login`). Але у вікні «Увійти на Шафу» вона **увійшла**: `shafa.ua/uk/new` показує форму «Додати товар» (зверху банер «Імпортувати товари», блок «Додайте фото товару», поле «Назва» нижче). Тобто `Session.open_form()` (`robot/browser.py`) після `goto(load)` + пауза 2–3 с не знаходить `input[name=titleUk]` — форма на повільному ноуті не встигає (або селектор змінився — перевір на знімку довідника/живій сторінці лише читанням).
2. `robot --login` і кнопка «Увійти на Шафу»: вікно Chrome закрили хрестиком — процес **висить** (`wait_for_manual_login`, цикл `while context.pages`), панель «Відкрито вікно входу…» без кнопок, допомогло лише перезавантаження.
3. Майстер (`wizard.py`): секрети через `getpass` — **Ctrl+V у cmd вставляє символ `\x16`**; ключ ШІ → 400, токен → traceback `httpx InvalidURL '\x16'`. Правий клік вставляє невидимо, кілька кліків — кілька копій.
4. Майстер завжди пропонує `C:\Users\<вона>\Шафа`, а не поточну головну папку → Enter повертає C:.
5. Перевірка «група коментарів» одразу після прив'язки: Telegram віддає `linked_chat_id` із затримкою кількох хвилин.
6. ШІ ставить **рукавички** в «Аксесуари / Ремені та пояси / Ремені/Пояси» (у знімку довідника рукавичок немає).

## Що зробити
1. `open_form`: чекати **до 30 с**, що з'явиться форма (`input[name=titleUk]`) **або** URL з `/login`. Форма є → далі. `/login` → «немає входу» (як зараз). Ні того, ні іншого → **окрема** причина зупинки «Шафа не показала форму» (не «вхід»), **знімок екрана** у `<дані>/robot-shots/<час>.png` і URL у `robot-run.log`. Вхід і «немає форми» в UI — різні тексти.
2. Вікно входу: закриття хрестиком (Windows) має завершувати режим входу за ≤ 10 с — знайди, чому висить (зайві сторінки/service worker/фонова робота Chrome), обробляй відключення браузера. Запасне: у панелі кнопка «Я увійшов — закрити вікно» (штатне `context.close()`, щоб cookies записались). Ліміт очікування 15 хв → закрити штатно.
3. Майстер: зі секретів і id прибирати керівні символи й пробіли (`\x16`, `\r`, `\n`…); погане значення → зрозуміле «Ключ/токен вставлено з помилкою — встав ще раз», **без traceback**, і питати ще раз. Підказка в питанні: «вставка — правою кнопкою миші, один раз». `docs/install-windows.md`: замінити Ctrl+V на правий клік; додати «Блокнот: `notepad <дані>\.env`» як запасний шлях.
4. Майстер: Enter = **поточна** головна папка з `.env` (якщо є), інакше типова.
5. Група коментарів не знайдена → текст: «…прив'яжи групу; якщо щойно прив'язала — зачекай 5 хв і запусти ще раз».
6. Рукавички (і будь-що, для чого немає розділу в знімку довідника): не підставляти схожий розділ — Картка в «Проблеми» «немає підходящого розділу на Шафі». Перевір, чи є на Шафі розділ для рукавичок (лише читання каталогу, `--sync-catalog` якщо треба) — якщо є, додати в знімок.
7. `robot-run.log`: причина зупинки з деталями (URL, скільки чекали), без секретів.

## Тести
Повільна форма (з'являється на 10-й с) → не «вхід»; `/login` → «вхід»; ні те, ні те → нова причина + знімок; закриття вікна входу → режим завершується; `\x16` у секреті → прибрано; погане значення → без traceback; Enter у майстрі → поточна папка; розділу немає → Проблема.
