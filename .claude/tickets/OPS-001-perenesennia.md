# OPS-001 — перенесення пілоту з Mac на її Windows: `shafa transfer-pack` / `transfer-unpack`

**Вага:** середня (50–70 хв). **Модель:** Sonnet · High.
**Аналоги:** `ops/build_windows.py` (пакет), `config.data_dir`, `places.py`, `wizard.py` / `setup` (`.env`, «Enter лишає старе»), `import-old` (копіювання фото в теку програми), `db.connect` (міграції), `app quit`.

## Що сталось
Пілот 2 тижні працює на Mac Власника: дані `~/shafa-viktoria` (`shafa.sqlite` ~2 МБ, `borh/` ~200 МБ, `thumbs/`, `duplicates/`, json-стани), фото бота `~/Шафа/<номер>` (~150 МБ). Опубліковано 171, черги ШІ/сайту/бота, історія. Тепер усе має переїхати на її ноутбук (Windows, `D:\shafa`, там уже стара установка зі своєю базою і `.env`). Вручну це ~10 кроків з ризиком помилки (не той файл, замки, два боти на одному токені). Абсолютних шляхів у базі немає (перевірено Архітектором) — база переносна.

## Що зробити
### A. `shafa transfer-pack --out <zip>` (на Mac)
1. Відмовляє, якщо програма/робот/бот працюють (замки `*.lock`, `bot.json`, `robot.json`) — «Спершу "Вийти"».
2. Знімок бази — `sqlite3` backup API (не копія файлу), `PRAGMA integrity_check` = ok.
3. У zip: `data/shafa.sqlite`, `data/borh/**`, `data/duplicates/**`, json-стани (`alerts-last`, `report-last`, `post-changes`, `photos-purged`, `presence-leftovers`, `rehearse-last`, `health-last`), `root/<номер>/**` з `SHAFA_ROOT_DIR`; `manifest.json` (версія програми, `user_version`, лічильники статусів, кількість файлів і сума розмірів, sha256 бази).
4. **НЕ** пакувати: `.env` і будь-які секрети, `robot-profile/` (вхід на Шафу — її), `*.lock`, `ui.*`, `bot.json`, `robot.json`, `thumbs/` (відтворюються), `robot-screens/`, `sync-cache/`, `*.bak*`, `*.до-оновлення`, логи.
5. Несекретні налаштування з `.env` — у `manifest.json` → `settings` (лише ключі `SHAFA_*` і `TELEGRAM_*_ID`; токени/ключі — ніколи).
6. Вивід: шлях zip, розмір, лічильники.

### B. `shafa transfer-unpack --zip <zip>` (на Windows; працює і на Mac у тестах)
1. Відмовляє, якщо програма працює. Версія схеми zip > схеми програми → відмова «спершу онови програму».
2. Наявна база в теці даних → перейменувати в `shafa.sqlite.до-перенесення-<дата>` (нічого не видаляти).
3. Розпакувати `data/` у `config.data_dir()`, `root/` — у її `SHAFA_ROOT_DIR` (тека з її `.env`); наявні теки з тим самим номером — не перезаписувати, складати в `<номер>-перенос` і назвати у виводі.
4. `.env`: секрети **не чіпати**; із `manifest.settings` дописати/оновити лише `SHAFA_*` і `TELEGRAM_*_ID` (показати, що змінилось: ключ, було → стало). `SHAFA_ROOT_DIR` — лишається її.
5. Перевірка: відкрити базу через `db.connect` (міграції), `integrity_check`, лічильники статусів = manifest; кількість файлів = manifest; для кожної Картки `new/review/approved` бот-поста — тека з фото є (нема → список).
6. Вивід: «Перенесено: опубліковано N, на перевірці N, … Фото: N тек. Змінено налаштувань: … Перевір: бот у `.env` той самий, що на Mac (інакше два боти)».

### C. Інструкція
Розділ «Перенесення пілоту з Mac» у `docs/install-windows.md`: по одній дії, з очікуваним результатом. Обов'язково: **спершу «Вийти» на Mac і переконатись, що бот на Mac зупинений**, потім unpack у неї, потім ярлик; на Mac програму більше не запускати з цим `.env` (той самий токен = конфлікт `getUpdates`).

## Заборонено
Пілот (`~/shafa`, `~/shafa-viktoria`, `~/Шафа`), жива Шафа, робот, sync, канал, бот, сайт, ШІ, `.env`, програма на 8765 — не чіпати й не запускати. `robot/guard.py`, `robot/browser.py`, `db.py`, `rules.py`, `shafa-catalog.json` — не змінювати. RULES_VERSION не піднімати. Тести — лише `tmp_path` (підставна тека даних і корінь). Вивід обрізай (`| tail -n 40`).

## Тести (мінімум)
- pack при запущеній програмі → відмова. pack → zip без `.env`, `robot-profile`, замків, `thumbs`; manifest без секретів (перевірити, що жодне значення токена/ключа з тестового `.env` не потрапило в zip).
- unpack у порожню теку → лічильники = manifest, база відкривається, міграції ок.
- unpack поверх наявної бази → стара перейменована, не видалена.
- Тека з тим самим номером уже є → `<номер>-перенос`.
- `.env` у неї: секрети без змін; `SHAFA_DAILY_*` оновлено; `SHAFA_ROOT_DIR` її.
- Схема zip новіша → відмова.
- Шляхи з кирилицею й пробілами (`Шафа`, `Telegram Desktop`).
