## Навіщо
Поля, які вимагають «подивитися на фото й зрозуміти текст», заповнює Claude: назва, розділ, розмір, колір, бренд, матеріал верху й підкладки, сезон/тип/стиль (коли очевидно), ключові слова, перевірка порядку фото. Код (CORE-002) уже дає ціну, стан, опис, устілку, мембрану — їх ШІ **не** перезаписує. Правила — `docs/rules.md` розділи 5–10, форма Шафи — `docs/research/shafa-form.md`.

Чого бракує (чоловіче взуття — розміри; сумки, гаманці, ремені — поля)? Список прогалин у звіт; їх заповнимо пізніше роботом.

## Що зробити (план; уточнимо після Фази 0)
1. **`src/shafa/catalog.py`** — довідники Шафи як константи (розділи, кольори, матеріали, розміри). Функції перевірки «значення є в довіднику».
2. **`src/shafa/photos.py`** — підготовка фото для ШІ: поворот за EXIF, зменшення до N px, JPEG у пам'яті. Оригінали не змінюються.
3. **`src/shafa/ai.py`** — один запит на Картку: фото + чистий текст поста + поля коду (ціна, стан, устілка, мембрана) + інструкція за `docs/rules.md` 5–10 → JSON за схемою. Інструкція — окремий файл `src/shafa/prompts/blank.md` (щоб правити без коду).
   Поля відповіді: `title`, `section` (повний шлях), `sizes` (1–2), `colors` (1–2), `brand`, `material_upper` (список), `material_lining`, `season`, `type`, `style`, `teen` (так/ні для дитячого), `gender` (для аксесуарів), `keywords` (4–6), `photo_order` (переставлені імена файлів або без змін), `doubts` (список полів, де модель не впевнена, з короткою причиною).
4. **Перевірка відповіді кодом:** розділ і кольори — з довідника; назва без контактів і ≤ ліміту Шафи; розмір відповідає розділу (підказка за розміром із `rules.md` §6). Порушення → поле в «жовтих» з причиною, а не падіння.
5. **База:** таблиця бланків (поле → значення, жовте/ні, причина), лічильник вартості (токени вхід/вихід, ціна в центах) на кожен запит. Картка після успішного бланка: `new` → `review`. Помилка API → `problem` з кодом `ai_error` і зрозумілим текстом.
6. **CLI:** `python -m shafa fill --db … --root … [--post N] [--limit K] [--dry-run]`. `--dry-run` — зібрати запит, порахувати фото й орієнтовну вартість, **нічого не надсилати**. Без `--post`/`--limit` — не більше 10 Карток за запуск (захист від випадкових витрат).
7. **Тести** — без мережі: підставний клієнт API, вигадані відповіді (добра, з помилковим розділом, з невідомим кольором, обрізана/невалідна, помилка API). Фото — згенеровані крихітні з EXIF-поворотом.
8. **Ручний прогін на 7 прикладах** (після дозволу Власника на витрати, ~кілька центів): таблиця у звіт — номер · назва · розділ · розмір · колір · бренд · матеріал · жовті поля · ціна запиту. Власник порівняє з її реальними оголошеннями.
9. **Документи:** `CLAUDE.md` — команда `fill`, де лежить інструкція; TD — за потреби.
10. **Журнал** — останнім комітом.
