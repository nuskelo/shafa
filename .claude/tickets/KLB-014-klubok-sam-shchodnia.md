## Навіщо
Жива база 22.11: **з 12.11 жодної сесії Клубку** — у черзі 232 пари (хвиля 1 — 146, бот — 83, хвиля 4 — 3), виставлено всього 19. Сесії Шафи Власник запускає майже щодня (70, 71, 72 — 21–22.11). «Обновить все» (KLB-004/013) і дублі (KLB-011) вже працюють самі; не вистачає лише щоденного старту публікації.

## Що зробити
1. **Щоденний автостарт** — клас за зразком `klubok_renew.Daily` (`robot/klubok_renew.py:261`, підключення — `app.klubok_daily`, `app.py:110`): тик раз на хвилину, запускає той самий процес, що кнопка «Старт» (`web.klubok_robot_post` `action == "start"`: `--klubok-publish --db … --root … --limit min(left, 30)`, журнал `klubok-run.log`).
   Умови запуску (усі): `SHAFA_KLUBOK` увімкнено; `SHAFA_KLUBOK_AUTO` не вимкнено (типово «так»); програма відкрита; робот вільний (`lock.busy`); `klubok_control.state(...)`: `can_start` і `left ≥ 1`; сьогодні автостарту ще не було; **і одне з двох:**
   - а) сьогодні була сесія Шафи, що закінчилась спокійно (`sessions.site = 'shafa'`, `ended_at` сьогодні місцевого часу, `stop_code` спокійний — як `publish.py:590`) — Клубок іде одразу після неї;
   - б) настала `SHAFA_KLUBOK_AUTO_AT` (типово «21:00»).
   Позначка «сьогодні вже запускали» — `<дані>/klubok-auto.json` (день, час, id сесії) — пишеться **в момент запуску**; один автостарт на добу. Кнопка «Старт» лишається (ручний запуск автостарт не блокує й навпаки — лише ліміт доби).
2. **Не запускати**, якщо сьогоднішня сесія Клубку вже зупинилась гучно (`klubok_publish.LOUD`: капча, невпевнено, немає входу, 429, знімок, заборонено, помилка) — це питання людини; тривога про таку зупинку вже є.
3. **Панель Клубку:** рядок «Автостарт: сьогодні після сесії Шафи або о 21:00» / «запущено сьогодні о 21:34» / «вимкнено». Налаштування — блок «Клубок»: «Виставляти самому щодня» (так/ні) і час.
4. **Дрібниця (окремий коміт):** `prompts/duplicate-klubok.md` — «why» лише українською (живе 18.11: «Однако…»).

## Фаза 0 (гіпотези, звіт без зупинки)
- HYP-1: `klubok_control.state` дає `can_start`/`left` без браузера й мережі — можна кликати з фонового тику (файл:рядок).
- HYP-2: кінець сесії Шафи видно з `sessions` (`site`, `ended_at`, `stop_code`), спокійні коди — як `publish.py:590`.
- HYP-3: `klubok_renew.Daily` (тик, позначка доби, `busy`) годиться за зразок; два «щоденні» (оновлення 20:00 і автостарт) не заважають — робот один, другий чекає наступного тику. Сесія публікації сама робить «Обновить все» на початку (KLB-013).
- HYP-4: процес запуску — той самий, що в `web.klubok_robot_post` (одна функція для кнопки й автостарту, без копії).
