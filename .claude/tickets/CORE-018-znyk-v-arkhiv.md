# CORE-018 — пост бота зник з каналу → Картка сама в Архів (не чекати робота)

**Вага:** мала (30–40 хв). **Модель:** Sonnet · High.
**Аналоги:** `robot/publish.py` — `_post_deleted` (~786, `POST_DELETED`, `POST_DELETED_TEXT`, подія `post.gone`), `from_bot` (~275); `site.py` — `_release` (~645, GONE → `cancelled`), нічна перевірка (`post_checks.gone_at`, ~611); `web.py` (~227, текст причини `post_deleted` в Архіві).

## Що сталось (26–27.10, пілот)
- Сесія 36: Влад схвалив 10 нових Карток; 5 з них (7016, 7019, 7022, 7023, 7024) робот відсіяв перед публікацією — пости видалено з каналу (продано; звірено вручну через `forwardMessage`: «message to forward not found»).
- 27.10 сайт при виході побачив зниклими 7027, 7032, 7033, 7034 (`post.gone`, `site_jobs` → `cancelled`), але їхні Картки лишились `new` → потраплять у ШІ (гроші) і «На перевірку» (зайва робота людині).
- Причина: про зникнення знають нічна перевірка і сайт, але Картку в Архів переводить лише робот у момент публікації.

## Що зробити
1. Спільна функція (напр. `review.archive_gone(conn, post_id) -> int`, винести з `_post_deleted`, не дублювати): якщо `posts.source = 'bot'` — усі Картки цього поста в `new` / `review` / `approved` → `archived`, `problem_code = 'post_deleted'`, `problem_text = POST_DELETED_TEXT`, `archived_at`. Картки з `shafa_id` чи `published` — **не чіпати**. Старі пости (`borh-`, source export) — **ніколи** (рішення: видалений старий пост ≠ продано).
2. Викликати там, де вже є GONE: `site._release` (GONE), нічна перевірка (коли ставиться `gone_at`), `robot._post_deleted` (через ту саму функцію). Подія `post.gone` з текстом «… Картку N прибрано в Архів» — одна на пост, без дублів.
3. Разове прибирання на старті програми (ідемпотентно): Картки `new/review/approved` бот-постів, у яких `site_jobs.state = 'cancelled'` через зникнення **або** `post_checks.gone_at IS NOT NULL` → як п. 1. Тільки ці ознаки; «невідомо» (`unknown_since`) — ніколи не підстава.
4. ШІ (`fill`, пакети) і пробний прогін не беруть `archived` — перевірити тестом, що після п. 1 Картка не йде в ШІ.
5. В Архіві причина показується як зараз («Пост видалено — продано»); «Повернути» лишається (якщо помилка).

## Тести (мінімум)
- Бот-пост GONE на виході на сайт → Картка `new` → `archived` + `post_deleted`; `review`/`approved` — так само.
- Нічна перевірка GONE → те саме.
- Старий пост (`borh-`, export) GONE → Картка без змін.
- `published` / з `shafa_id` → без змін.
- UNKNOWN → без змін.
- Разове прибирання на старті: `cancelled`/`gone_at` → в Архів; другий запуск нічого не міняє.
- Робот `_post_deleted` працює як раніше (наявні тести зелені).
- Після архівації Картка не йде у `fill`.
