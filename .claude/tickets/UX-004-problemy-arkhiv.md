# UX-004 — Проблеми і Архів: що сталось, що робити, без пасток

Вага: середня-велика · Модель: Sonnet · High · Аналоги: UX-003 (PR #81), UI-007. Дизайн НЕ міняти — лише тексти і поведінка (нові кнопки — існуючими класами).

## Навіщо
Програма переходить до Вікторії (працює сама). UX-аудит 31.10: у Проблемах їй часто не ясно, що сталось і що натиснути; є дві пастки, через які продана пара може піти на Шафу або Картка «зникне».

## Пастки (спершу)
- **B10 «Повернути» проданої з Архіву.** Картку з причиною «Пост видалено з каналу — продано» (`post_deleted`/`post.gone`) можна повернути без попередження → схвалити → робот виставить продане (archived.html:20-24; card.html:330; review.py:568-575). Треба підтвердження (confirm у формі, без JS-alert якщо можна — сторінка-підтвердження чи `?confirm=1`): `Цей пост видалено з каналу — пару, мабуть, продано. Повернути все одно?`.
- **B3 Картка зникає з усіх вкладок.** Після «Перезаповнити пакетом» статус `new` → її нема ні в одній вкладці; повідомлення «картки пішли на ШІ» — навіть без ключа ШІ; сторінка Картки сіра без кнопок і пояснень (web.py:1217-1223, :142; card.html:308). Треба: на Картці `new` у пакеті — `Ця Картка чекає на ШІ (відправлено ДД.ММ о ГГ:ХХ). Зазвичай до години — потім з'явиться в «На перевірку». Правити зараз не можна.`; ШІ недоступний (нема ключа/бюджету) — не казати «пішли на ШІ», а `ШІ зараз недоступний — Картку поставлено в чергу; скажіть Власнику.` Лічильник `Чекають на ШІ: N` біля вкладок (якщо N>0).
- **B4 Неправдива підказка many_items** (web.py:161): обіцяє «розбирається сам, якщо кожен розмір окремим пунктом», а `SPLIT_SIZES=False` (пост 3654 так написано і він у Проблемах) → `У пості кілька пар чи розмірів — робот публікує лише одну пару на пост. Опублікуйте на Шафі вручну (і натисніть «Опублікувала вручну») або «В архів».`

## Рішення Влада: «Опублікувала вручну» (B5)
Для `many_items`, `no_section`, `publish_error`, `robot_*`, `possible_duplicate` — кнопка `Опублікувала вручну → вставити посилання`: поле для посилання shafa.ua/…/item/<id> → Картка в «Опубліковані» з цим `shafa_id`/посиланням (так само, як існуюча дія `on_shafa` — перевикористати її). Посилання перевіряти формою (shafa.ua, є номер); без мережі. Після цього нічні «Продано»/зняття працюють для неї як для звичайної опублікованої.

## Підтвердження незворотного (B5, B14)
- «В архів» з Проблем для кодів з `NO_RESTORE` (повернути не можна) → підтвердження `Картку не можна буде повернути. Точно в архів?`.
- «Відхилити» на Картці → назва `Не публікувати (в Архів)`; після — `Картку «<назва>» відкладено в Архів на 7 днів. [Повернути]` (якщо повернути можна).

## Тексти Проблем (web.py:161-237, problems.html, card.html, rules/scan тексти)
Один тон — «ви» на екрані. Для кожного коду: що сталось + що натиснути, кнопка має існувати.
1. **B11** Картка в Архіві: `В Архіві: <причина>. Видалиться з програми ДД.ММ (фото в папці лишаються).`; якщо повернути не можна — `Повернути не можна: <чому>`.
2. **B19** `publish_error` і `shafa_declined` звучать однаково → `Шафа не прийняла при публікації` / `Шафа відхилила оголошення`.
3. **B20** `size_gone`: Картка каже «Якщо продано — «В архів»», а кнопки нема; список каже «нічого не роби» → додати `size_gone` в `ARCHIVE_CODES`; текст `Розмір X прибрали з поста. Продано — «В архів». Не продано — поверніть розмір у пост і «Перевірити ще раз».`
4. **B21** `photos_missing`: причина схована під «Подробиці для Власника» → показувати відкрито; додати «В архів».
5. **B22** `robot_*`: лише «Перевірити ще раз» (ходить колом); у тексті назва скриншота `2026-…-нема-поля.png` → кнопки `Повернути на перевірку (виправити поля)` і `В архів`; назву файла — під «Подробиці для Власника».
6. **B23 / C2** `robot_logged_out`: «Власник: python -m shafa robot --login» (web.py:172) → `Робот вийшов із Шафи. Натисніть на панелі «Увійти на Шафу», увійдіть як завжди й закрийте вікно. Потім «Перевірити ще раз».` (кнопка з UX-002).
7. **B24** `stale_rules`: «Натисніть «Перерахувати правилами» (вкладка ШІ)» — вкладки нема → `Програму оновлено — Картку треба переглянути ще раз. «Перевірити ще раз» поверне її в «На перевірку», правки збережуться.` (robot/publish.py:79-81 — лише текст).
8. **B25** `publish_error`: «(текст помилки вище)», а він нижче і згорнутий → текст помилки Шафи відкрито; додати `Повернути на перевірку (виправити)`.
9. **B26** «Перевірити ще раз» на `many_items`/`no_section` старого поста → «Папку перевірено: проблема лишилась» → текст за кодом; для старих постів (borh) кнопку не показувати.
10. **B27** `no_section` (scan.py:75) «Немає підходящого розділу (окуляри, парасольки…)» для «Термокофта» → `Робот публікує лише взуття й аксесуари. Цю річ опублікуйте на Шафі вручну або «В архів».`
11. **B28** «Опубліковані»: «Схоже: https://… — ШІ: інша пара (абзац)» → `Перевірено: на Шафі є схоже оголошення — це інша пара` + посилання «подивитись».
12. **B29** «Робот пропустить: Матеріал верху…» → додати `Схвалити можна — ці поля на Шафі будуть порожні.`
13. **B35** /refill: без заголовка, «нова інструкція ШІ…≈$X (пакетом…)» → заголовок `Заповнити заново`; текст `ШІ став розумнішим: N Карток він, можливо, заповнив би краще. Ваші правки збережуться. Результат — до години; на цей час Картки зникнуть із «На перевірку».`; мітка «заповнено старими правилами» → `можна заповнити краще`.
14. **B36** Вступ Архіву → `Тут Картки, які не підуть на Шафу. Через 7 днів вони зникають з програми (фото в папці лишаються).`
15. **C29** «Папка borh-3659» у Проблемах/Архіві → `Старий пост 3659`.

## Фаза 0 (HYP)
- HYP-1: «Повернути» для `post_deleted` доступне без перевірки (B10).
- HYP-2: Картка `new` після «Перезаповнити пакетом» не видна в жодній вкладці (B3).
- HYP-3: `on_shafa` можна викликати з довільним посиланням для кодів з B5.

## Тести
- Повернути `post_deleted` без підтвердження → не повертає; з підтвердженням → повертає.
- «Опублікувала вручну» з посиланням → Опубліковані, `shafa_id` записано; погане посилання → помилка, Картка на місці.
- Картка `new` у пакеті → пояснення; нема ключа → без «пішли на ШІ».
- `size_gone`, `photos_missing`, `robot_*` мають «В архів»; `robot_logged_out` без «python -m».
- Нема «borh», «вкладка ШІ», «python -m» у текстах для неї.
- Форми `action/value/name` існуючих кнопок — без змін.
