## Навіщо
Перший крок до виставлення її пар на Клубок: програма з перевіреної Картки складає оголошення Клубку, робот заповнює форму — **лише на підставному Клубку**, без публікації, без живого сайту, без змін бази (міграція — KLB-002).

## Вхідні дані (не в репо, лише читати; `~/klubok-4/`)
- `api/categors.json` (`{status, categories:[{cat_id, name, level, filters, secondary_cat, sub_cat}]}`), `api/filters.json` (`{status, filters:{"1": {name:"SEX", values:[{key,value}]}, …}}`), `api/secondarycat_all.json` (характеристики — у v1 не потрібні).
- `add.html` — порожня форма **додавання**: та сама розмітка, що й редагування, кнопка «Опубликовать», `reCaptcha()` → `grecaptcha.execute` → `userItem.captcha` → `POST /api/add-edit-used` → успіх `/payment/{id}?action=used-submit-ok-logged`, помилка `/error429?…`.
- `*.html` (40) — сторінки редагування її оголошень (`data-user-item`, `data-selected`); `manage-*.html`, `renew-all.txt` — для KLB-003/004.
- **Секрети:** `token` у `data-user-item`, cookies — нікуди не копіювати.

## Ітерація 1 — рішення по Фазі 0 (Архітектор · 10.11)
- **D1 · бренд — згода, вузько.** Клік по посиланню дозволено лише коли одночасно: елемент `a.dropdown-item`, `href` рівно `#`, усередині `#filter2`, текст не збігається із забороненими словами. Будь-яке інше `a` — `Forbidden`. Мережевий блок небезпечних адрес (`renew|marksold|…`) діє незалежно від кліку. Тести: підказка бренду — клік є; `a.dropdown-item href="/renew/all"` у `#filter2` — блок; `a href="#"` поза `#filter2` — блок.
- **D2 · чоловічі сумки — згода.** Поле `gender` Картки «Для чоловіків» → `Мужское / Аксессуары / Мужские сумки` (1000990), гаманці/портмоне → `Мужское / Аксессуары / Портмоне, кошельки` (1000998); інакше (жіноче або порожнє) — жіночі листки з таблиці. Обидва листки — у знімок.
- **D3 · типи без рядка.** Малюки «Босоніжки» → `Детское / Обувь / Летняя обувь` (1000391). **Барсетки → завжди 1000990** (чоловічі сумки). Авоськи, Органайзери, Кейси для косметики, Косметички, Аксесуари для сумок, Картхолдери, Ключниці, Затискачі, Візитниці → `Skip("klubok_no_category")`.
