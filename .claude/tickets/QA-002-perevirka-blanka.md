# QA-002 — перевірка бланка за знімком до схвалення

Модель: Sonnet · рівень: High. Основа — main після мержу PR #45 (ROBOT-010).

## Навіщо
Зараз бланк звіряється зі знімком розділу (`shafa-catalog.json`) лише коли робот уже бере Картку (`robot/plan.py: plan()`). Помилки (`PlanError`: обов'язкові поля без значення, немає фото/назви/ціни) і пропуски (значення немає у списку Шафи, поля немає в розділі) Влад бачить тільки після «Старт». Треба, щоб він бачив їх на Картці **до** «Схвалити», а Картка, яку робот точно не опублікує, не могла стати Схваленою.

## Що зробити
1. `robot/plan.py`: та сама перевірка без вимоги статусу «Схвалено» — напр. `precheck(card, root) -> Precheck(error: str | None, notes: list[str])`. Логіку `plan()` не дублювати: `plan()` викликає спільне ядро; поведінка `plan()` для робота не змінюється (наявні тести зелені).
2. Екран Картки (`templates/card.html`, `review.py`, `web.py`) для «На перевірку» і «Схвалені»:
   - `error` → червоний блок «Робот не зможе опублікувати: <текст>», кнопка «Схвалити» неактивна з цим поясненням (як `approve_block`).
   - `notes` → жовтий блок «Робот пропустить: …» по рядку на кожну (напр. «Тип: немає у списку Шафи — Челсі»). Схвалити можна.
   - Рахувати на льоту при відкритті Картки (знімок локальний, без мережі й ШІ). Список вкладки — лише позначка (значок/колір), без тексту.
3. Схвалення (`review.py`, дія `approve`): якщо `precheck().error` — не схвалювати, повернути текст (захист від старої сторінки).
4. Команда для вже схвалених: `fill --db … --precheck [--dry-run]` — для всіх «Схвалених»: з `error` → назад «На перевірку» з `problem_text` = текст (як «Схвалені, у яких змінився бланк, повертаються на перевірку»); вивід — по рядку на Картку, підсумок. `--dry-run` нічого не пише.
5. Після `--sync-catalog` (новий знімок) — нагадування в кінці виводу: «запустіть fill --precheck».

RULES_VERSION не піднімати (правила бланка не змінюються, лише показ).

## Тести
- `precheck` для Картки «На перевірку» з усім заповненим → без error/notes; без обов'язкового поля розділу → error; значення не зі списку → note; поле, якого нема в розділі → note.
- `plan()` для схваленої — без змін (наявні тести).
- Сторінка Картки: червоний блок + неактивна кнопка; жовтий блок; без блоків, коли все добре.
- POST «Схвалити» при error → статус не змінився.
- `fill --precheck`: схвалена з error → «На перевірку»; без error — лишилась; `--dry-run` — база без змін.
