# BOT-015 — бот: «📦 Лише в чергу Шафи» (пост уже є в каналі) + бот пам'ятає пости каналу

**Вага:** середня (50–70 хв). **Модель:** Sonnet · High.
**Аналоги:** `bot/core.py` — `_preview` (~715, кнопки), `_callback` (~784), `_publish`/`_published` (~844/937: `posts` source='bot', `_save_folder`, `_to_site`), `_channel_edit` (~427); `bot/presence.py` (тихе `forwardMessage` у службовий чат + видалення копії); `bot/telegram.py:136` (`allowed_updates`); `site.enqueue` (дата поста → `not_before`).

## Що сталось
Пілот працює на Mac Власника; коли Mac вимкнений/спить — бот не відповідає. 24–25.10 Вікторія публікувала пости **напряму в канал**, не через бота. Такі пости не потрапили ні в `posts`, ні в `~/Шафа/<номер>`, ні в чергу сайту → на Шафу/сайт через 7 днів не підуть. Bot API не дає історії каналу; `allowed_updates` зараз без `channel_post`, тож прямі пости бот не бачить навіть коли працює.

## Що зробити
### A. Кнопка «📦 Лише в чергу Шафи» у прев'ю чернетки
1. У `_preview` — третій ряд: `📦 Лише в чергу Шафи` (`callback_data` нового типу). Опублікувати / Редагувати / Скасувати — без змін.
2. Натиснула → **у канал нічого не шлемо, підпис не редагуємо**. Бот шукає в каналі пост з тим самим описом (див. B, C).
3. Знайшов **рівно один** → так само, як після публікації (`_published`), але без `send`/`_fix_link`/коментарів:
   - `posts`: `post_id` = номер з каналу, `date` = дата **з каналу** (локальна, як у `_published`), `text` = текст поста **з каналу**, `source='bot'` (щоб працювали presence, 7 днів, сайт, «Продано»);
   - фото → `_save_folder(post_id, photos)` (усі, до 10, у порядку надсилання);
   - `_to_site(...)` з датою з каналу → сайт через 7 днів **від дати в каналі**;
   - чернетка → новий стан `queued`, `post_id`, `folder_name`;
   - відповідь їй: «Пост N від <дата> — у черзі Шафи, фото: K. На Шафу — не раніше <дата+7>.»
4. Не знайшов або знайшов ≥2 → нічого не записує; відповідь: «Не знайшов у каналі пост з таким описом. Перешли мені цей пост з каналу — і натисни кнопку ще раз» (чернетка лишається з кнопками). Ніколи не вгадує.
5. Пересланий з каналу пост (є `forward_origin` типу `channel`, той самий канал) у чернетці → номер і дата беруться **з нього** без пошуку (текст звірити — не збігся → як п. 4).
6. Пост з цим номером уже є в `posts` (бот публікував або вже ставили в чергу) → «Пост N уже в черзі/опубліковано» і нічого не робить. Папка `~/Шафа/N` вже є → як зараз у `_save_folder` (`N-бот`) + повідомлення Власнику.

### B. Бот пам'ятає пости каналу
6. `allowed_updates` + `channel_post`. Нова таблиця (міграція в `db.py`, лише додати) `channel_posts(post_id PK, date, text, media_group_id, seen_at)`. Кожен `channel_post` нашого каналу (`TELEGRAM_BOT_CHANNEL_ID`) → запис (текст або caption; альбом — номер того елемента, де caption). Інших чатів не чіпати. Більше нічого з ними не робить (на Шафу/сайт — лише через кнопку з A).

### C. Пошук поста за описом
7. Спершу `channel_posts`; нема → тихий перегляд каналу: номери від `max(posts.post_id, channel_posts.post_id) + 1` і **назад** до `max − 300` (і вперед до 50 поспіль «не знайдено»), через `forwardMessage` у службовий чат (`disable_notification`) з одразу `deleteMessage` копії — як `presence.py` (перевикористати, не дублювати). Пауза ~1 с між запитами, 429 → `retry_after`. Ліміт — 400 запитів на один пошук; знайдені тексти кешувати в `channel_posts`.
8. Звірка тексту: нормалізувати обидва (нижній регістр, без емодзі, хештегів, посилань, @ніків, рядка «Пишіть сюди…», зайвих пробілів/пунктуації). Збіг = нормалізований опис з чернетки (`own_text`) **повністю міститься** в нормалізованому тексті поста **або** схожість ≥ 0,9 (`difflib.SequenceMatcher`). Ціна і розмір у тексті мають збігтися точно (числа з обох текстів — однакові множини), інакше не збіг.
9. Копії в службовому чаті не лишаються (не видалилась — як BOT-014, `presence-leftovers.json`).

## Гіпотези (Фаза 0 — перевірити й записати у handoff)

## Заборонено
Живий канал, бот, Шафу, сайт, ШІ не запускати; `~/shafa`, `~/shafa-viktoria`, `.env` не чіпати; програму на 8765 не чіпати. `robot/guard.py`, `robot/browser.py`, `rules.py`, `shafa-catalog.json` — не змінювати. `db.py` — **лише** нова міграція з таблицею `channel_posts`. RULES_VERSION не піднімати. У каналі нічого не редагувати й не видаляти (лише копії у службовому чаті). Тести — лише `tmp_path` і підставний Telegram. Вивід обрізай (`| tail -n 40`).

## Тести (мінімум)
- Кнопка є в прев'ю; «Опублікувати» працює як раніше.
- Знайдено в `channel_posts` → `posts` (source bot, дата з каналу), папка з усіма фото, `site_jobs.not_before` = дата каналу + 7 днів, у канал нічого не відправлено, `edit_caption` не викликано.
- Знайдено переглядом (підставний `forwardMessage`) → те саме; копії видалено; кеш заповнено.
- 0 збігів / 2 збіги / ціна інша → нічого не записано, текст «Перешли мені пост».
- Пересланий пост з каналу → без перегляду; текст інший → відмова.
- Пост уже в `posts` → «уже в черзі», нічого не змінено.
- `channel_post` чужого чату — ігнор; свого — запис у `channel_posts`.
- 429 під час перегляду → пауза, не «не знайдено»; ліміт 400 → «не знайшов».
