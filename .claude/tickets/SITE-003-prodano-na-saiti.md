## API (відповідь Архітектора сайту 18.10)
- `POST /api/integration/v1/products/by-post/{postId}/sold`, без тіла. 200 `{id, postId, status:"Sold", changed:true}`; повтор — 200 `changed:false`; пари немає — 404 (не помилка: записати й більше не слати). Скасувати через API не можна (лише адмінка) — тому помилкове «Продано» дороге.
- `GET /api/integration/v1/products/post-ids` → `{"postIds":[…], "count":N}` — усі пари не Sold із номером поста, за зростанням, без сторінок.
- Hidden із видаленим постом — теж «Продано».
- Ключ і ліміт ті самі (60/хв, спільний; 429 → Retry-After).
- Поки на сервері немає (404 на сам маршрут / 405) — нічого не ламати: записати «сайт ще не вміє Продано», спробувати наступної ночі. Відрізняти 404 «маршруту немає» від 404 «пари немає» за тілом відповіді (подивитись у контракті після оновлення; інакше — за наявністю `postId` у тілі).

## Зробити
1. Замінити заглушку TD-035 на справжній виклик `sold`. Закрити TD-035.
2. Старі пари: щоночі `GET post-ids` (раз на ніч) → у `post_checks` (`old=1`) нові номери; номери, яких у списку більше немає (продані в адмінці) — не перевіряти. Перевірка по колу, найдавніше перевірені першими, ≈1/с, скільки встигне до ранку (06:00).
3. **Прохання сайту (обов'язково):**
   a) `postedAt` у PUT = **момент відправки на сайт** (UTC, ISO), не дата поста — інакше пара після 7 днів не потрапляє в «Новинки». Дата поста лишається в нашій базі.
   b) «Продано» — **лише** коли Telegram явно відповів «повідомлення не знайдено» (для forwardMessage: `message to forward not found` / `MESSAGE_ID_INVALID`; задокументувати точні тексти в коді). Немає прав, 429, мережа, 5xx, будь-що інше — нічого не слати.
   c) **Запобіжник:** якщо за одну ніч «видалено» > 20 постів (налаштування, типово 20) — **нічого** з цієї ночі на сайт не слати, повідомити Власнику в бота («За ніч зникло N постів — схоже на збій, “Продано” не надіслано. Перевір канал»). Наступної ночі — знову перевірити; Власник може в «Налаштуваннях» натиснути «Надіслати відкладені Продано».
4. Шафа — без змін (не публікувати видалене вже зроблено в SITE-002).
5. Панель: «Сайт: … · продано за тиждень K · відкладено (запобіжник) M».
