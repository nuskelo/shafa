# QA-005 · Перевірка «день Вікторії»: сценарії на підставних Шафі й Клубку, «мавпа», бот наживо в тестовому чаті

**Вага:** звичайна (без міграції). **Автор:** Архітектор («Шафа + сервер») · 26.11.2026
**Гілка:** `fix/QA-005-den-viktorii` від свіжого `origin/main` (після UX-010). Перший коміт — цей тікет + попередній handoff в archive.
**Модель:** Sonnet · high

## Навіщо
У суботу 28.11 програма переїжджає на Windows Вікторії, і без нас поруч вона має працювати без сюрпризів. Перед цим проганяємо **всі життєві сценарії** на підставних Шафі (`--fake-shafa`) і Клубку (`klubok_fake`) і дивимось, як бот виглядає в справжньому Telegram. Живу Шафу, живий Клубок, живу базу й живий бот **не чіпати**.

## Частина A — сценарії
Для кожного сценарію: знайти тест, що його вже покриває (файл::тест), або дописати новий (unit чи Playwright на `--fake-shafa`/`klubok_fake`, порт ≠ 8765). Що впало — виправити тут же малим комітом (якщо правка > ~50 рядків або міняє поведінку — не правити, записати в звіт як BUG).

Шафа:
1. Чиста установка, перший запуск без профілю: Chrome не відкривається, панель каже «спершу увійдіть», «Старт» пояснює чому.
2. Вхід злетів до «Старт» → жовта панель, сесія не починається; після вікна входу → «Вхід є — можна «Старт»».
3. Вхід злетів посеред сесії → стоп, гучне «⛔» з підказкою входу (hints.py).
4. Подвійний клік «Старт»; «Старт» під час перевірки входу; «Старт» під час фонового «Мої речі» — рівно одна сесія.
5. Пауза / Продовжити / Стоп на кожному етапі: «Мої речі», форма, фото, пауза між парами, `wait_channel`.
6. «Вийти» посеред сесії → Картка `publishing` не губиться; наступний «Старт» — без дубля (recover / `publish_uncertain`).
7. Ноутбук «заснув» (стрибок годинника `SLEEP_JUMP`) посеред паузи й посеред форми.
8. Telegram 429 / таймаут на перевірці каналу → «Відкладено» / `telegram_busy` (ROBOT-020).
9. Ліміт доби досягнуто; сесія через північ (ліміт нового дня).
10. Дубль: ШІ `no` / `yes` / `unsure`, ШІ без бюджету.
11. Пост зник з каналу перед публікацією → Архів, не публікується.
12. Фото «0 з N» / частково → `robot_photos`; 3 поспіль → `streak`.
13. Шафа відхилила (DECLINED) → Проблема `shafa_declined` з підказкою.
14. Порожня черга → «Старт» каже, чому нічого не робить.
15. Бюджет ШІ вичерпано посеред пакета → гучна подія, Картки не губляться.
16. Картка з жовтим: «Так, вірно» / зміна / «Схвалити і далі» / «Скасувати схвалення»; «Повернути» з Архіву.
17. Сервер обміну недоступний (ssh код 255) → програма працює, у бот не спамить, обмін наздоганяє пізніше.

Клубок:
18. Вхід злетів → автостарт не йде, кнопка відкриває `/signin`.
19. Автостарт після сесії Шафи; ліміт доби; капча / 429 → стоп із підказкою.
20. «Схоже, продано» → «Так» / «Ні».
21. Шафа й Клубок одночасно → працює лише один робот, другий чекає й каже чому.

Бот:
22. Обидва чати; тихі/гучні; живе повідомлення не частіше 20 с; підсумок > 4096 ділиться; один чат недоступний — другому без дублів.

Windows:
23. Шляхи з кирилицею й пробілами (`D:\Шафа`, тека даних з пробілом); `pythonw` без вікон консолі (у т. ч. `ssh`, `--login-check`, `--listings-refresh`). Подивись останній прогін `windows-tests` на main: що падає / пропускається.

«Мавпа»: `caffeinate -i make monkey SEED=N 2>&1 | tail -n 40` для SEED = 1, 7, 11 (і Клубок, якщо мавпа його вже знає — TD-076). Знахідки → розібрати: справжній баг чи хибна.

## Частина B — бот наживо в ТЕСТОВОМУ чаті
Команда `python -m shafa alerts-preview --chat <id>` (токен — лише зі змінної середовища `TELEGRAM_BOT_TOKEN`, ніколи не з `.env` пілоту): шле в один чат по зразку **кожного** виду повідомлень на штучних даних — початок сесії Шафи й Клубку, живе повідомлення (3 редагування з паузою 25 с), підсумок із розгортаємими блоками (короткий і довгий > 4096), «⛔ Робот зупинився» (вхід, капча, `telegram_busy`), нова Проблема (дубль із фото-заглушкою), ШІ почав / закінчив, «🕓 Фонові події». Без бази пілоту, без мережі, крім Telegram. Влад запустить її сам із токеном тестового бота @shafa_test_vlad_bot і своїм chat id і подивиться на телефоні.
