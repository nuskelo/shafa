# ROBOT-013 — блок розміру аксесуарів, якого немає в знімку (шапки, шарфи, рукавиці…)

**Вага:** середня (≈ 60 хв). **Аналоги:** CORE-012 (`robot/plan.py::block_sizes`, `OTHER_SIZE`), `robot/sync.py::read_size_block`/`size_block_entry`, ROBOT-012 (`form.py`, поле-список без поля введення).

## Що сталось (22.10, Сесія 31, пілот)
Пост 6454 (шапка Michael Kors, розділ «Аксесуари / Головні убори / Шапки») → `publish_error`: «size: Потрібно вибрати розмір речі». На скриншоті `~/shafa-viktoria/robot-screens/20261022-111812-6454-після-кліку.png` форма має обов'язковий блок **«Виберіть розмір \*»** з кнопками XXS/S4 … One size, **Інший**, 58…35. Робот його не заповнив: у знімку `shafa-catalog.json` (checked 19.10) для «Шапки» `size_block` немає.
Знімок: з 51 розділу «Аксесуари» `size_block` є **лише в 1** («Рукавички»). Тобто `read_size_block` під час sync майже завжди повертав `None` (ймовірно, блок ще не намальований / інший заголовок). Так само можуть впасти шарфи, рукавиці, мітенки, баффи, снуди тощо. Клік уже був — Шафа не прийняла, дубля немає.

## Що зробити
1. **Наживо, не лише зі знімка:** перед «Додати річ» для розділів «Аксесуари» робот читає форму: якщо є блок розміру (кнопки розмірів, заголовок «Виберіть розмір», `*` — обов'язковий) і нічого не вибрано — заповнює його тим самим правилом `block_sizes` (літерний з тексту → інакше «Інший»), з приміткою «Розмір: блоку не було в знімку — прочитано з форми». Використати `read_size_block` / `size_block_entry` (або спільну функцію) — один код для sync і для публікації.
2. **Звірка форми:** якщо обов'язковий блок розміру на формі є, а після заповнення нічого не вибрано — НЕ тиснути «Додати річ», Картка → Проблема `robot_field_missing` з причиною простими словами (робот іде далі — помилка однієї Картки).
3. **Sync:** виправити `read_size_block` так, щоб він бачив блок для «Шапки» (почекати появу кнопок, а не фіксовану паузу). Знімок НЕ перезаписувати в цьому PR (sync ~40 хв — окремо, з Власником).
4. Precheck (`required_gaps`) — без змін (знімок не знає блоку); у handoff — що «Перевірити ще раз»/повтор для 6454 після мержу дасть публікацію.
