## Що змінити в програмі

1. **style.css** — замінити повністю файлом з пакета. Лише системні шрифти, нічого ззовні, без анімацій (`* { animation:none; transition:none }`). Використовує `:has()` (Chrome/Safari/Edge сучасні — ок). Наприкінці файлу є кілька блоків-уточнень (перевизначення `.sp-row`, щільність) — вигляд правильний як є; чистити дублікати можна лише зі звіркою скриншотами.
2. **Перемикач теми** (`tema.html`) — у спільний шаблон (база/шапка) усіх сторінок, включно з Карткою (`header.top.top-card`). Тема зберігається в `localStorage["shafa-theme"]`; за замовчуванням — світла (системну не враховуємо — так вирішив Влад).
3. **Панель стану v2** (`panel-stanu.html`) — найбільша зміна:
   - Рядок «Сьогодні на Шафі: з минулих постів X з N · з нових (бот) Y з M · Схвалених K» розбити на окремі значення → 4 прямокутники `.stat` (перший — `.stat-key` «Сьогодні опублікує: до N Карток · ≈ T хв» з `robot-eta`).
   - ШІ: «Готові до перевірки» (посилання на /review), «Готові йти на ШІ», «Чекають своєї черги», «Нових постів з бота» (`.stat-warn`, коли > 0); «Готово о …» — `.sp-line` під цифрами; довгі пояснення — у `<details class="more-info sp-more">`.
   - Бот / самоперевірка / Сайт — дрібний список `.sp-li` праворуч.
   - Кнопки «Старт» (`.sp-start`) і «Пробно заповнити завтрашні» (`.sp-rehearse`) — у формі `.sp-actions` з тими самими `name/value`, що зараз (`action=start` / `rehearse`), токеном і `back`.
   - **Стани, яких немає в макеті** (робот працює / пауза / зупиняється / помилка / login_needed / stale / fake-режим / збої самоперевірки / ШІ працює або помилка): для них у CSS вже є класи — `.sp-robot.is-running|is-warn|is-error`, `.sp-error`, кнопка `.sp-stop` (червона, замість «Старт» коли робот працює), `.sp-li.is-warn|is-bad`, `.health-rows` всередині `.sp-li`, `.fake`. Усі тексти й кнопки, що зараз є в цих станах, мають лишитися. Крапки — ті самі `.dot-ok|warn|bad|idle`.
   - Панель оновлюється через `/robot/panel?back=…` (атрибут `data-panel`) — новий шаблон має віддаватися і там. Міні-панель на Картці (`?mini=1`, `.status.mini`) — без змін розмітки.
4. **Крапка «Бот»** у міні-панелі на Картці зелена, коли бот працює (у копії для макета була жовта `bot-no_token` — перевірити, що в програмі стан правильний).
5. **Сторінка підтвердження «Вийти»**: під нею рендериться панель `.actionbar` з «Зберегти» (form="settings") — у макеті схована CSS-правилом; краще не рендерити в шаблоні.

## Правила кольору (не порушувати)
- Помаранчевий — бренд і головна дія («Старт», активна вкладка, «Сьогодні опублікує»).
- Жовтий — **лише** «треба глянути» (жовті поля, «! 1 жовте поле», «→ Щоб схвалити…», «Нових постів з бота»).
- Зелений — «Схвалити», готово, «Картку схвалено». Червоний — лише проблеми й помилки.
- Контраст тексту ≥ 4.5:1 в обох темах (поточна палітра — ≥ 5:1).
