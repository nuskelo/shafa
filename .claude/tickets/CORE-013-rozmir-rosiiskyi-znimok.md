# CORE-013 — розмір взуття зник: у знімку назви систем розмірів російською

**Модель:** Sonnet · High. Гілка `feature/CORE-013-rozmir-znimok`.

## Що сталося (20.10, жива публікація)
Робот зупинився на пості 1427: «Шафа не прийняла товар: size: Потрібно вибрати розмір речі».
- ШІ відповів `sizes: ["41"]`, але в бланку `sizes = []`, жовте, причина «у цього розділу розміру немає» (`ai.py:390`).
- Причина: sync 19.10 (CORE-011/012) записав у `src/shafa/data/shafa-catalog.json` назви груп розмірів так, як віддала Шафа: у 15 розділах «Европейский» / «Украинский» / «Американский» замість «Європейський»… (до sync — лише українські).
- `catalog.size_system()` шукає лише `SIZE_SYSTEMS = ("Європейський", "Український")` → None → `catalog.sizes()` = [] → бланк без розміру, а `review.approve_block` пропускає `no_sizes` (думає, розміру в розділу нема) → Картку можна схвалити.
- Уражені розділи: Жіночі Кросівки, Оксфорди, Еспадрільї; Чоловічі Кеди, Черевики; дитячі (дівчатка/хлопчики/малюки) Кросівки, Чоботи, Балетки, Мокасини, Гумові чоботи, Бутси, Черевики.
- У пілотній базі вже уражені щонайменше: 1427 (problem), 1766, 3400, 3645, 3763, 3896 (approved), 4433, 4461 (review).

## Що зробити
1. **sync** (`robot/sync.py`, `section_entry`): назву групи розмірів зводити до української через `robot/lang.py` (`lang.ukrainian`), щоб знімок завжди мав «Європейський/Український/Американський».
2. **catalog** (`catalog.py`): при читанні знімка теж нормалізувати ключі `sizes` (захист від старого/майбутнього знімка). Не покладатися лише на файл.
3. Оновити сам `shafa-catalog.json`: перейменувати ключі в 15 розділах (скриптом, без живого sync). Перевірити: після зміни немає жодного російського ключа.
4. **Тести:** sync з «Европейский» → у знімку «Європейський»; `size_system`/`sizes` для «Жіночий одяг / Взуття / Кросівки» дає EU-розміри; бланк з `sizes ["41"]` у цьому розділі лишає 41; `approve_block` → `no_sizes` для взуття з порожнім розміром.
5. **Уражені Картки:** дати спосіб перебудувати бланк з уже збереженої відповіді ШІ, без нового запиту (як `fill --refill` / «Перерахувати правилами»). Схвалені з порожнім розміром → назад «На перевірку» (не публікувати автоматично). Описати в handoff точну команду для пілотної бази `~/shafa-viktoria/shafa.sqlite` (запускатиме Влад, не ти) і як знайти всі уражені (`blanks.field='sizes' AND value='[]'` у розділах з розмірами).
6. RULES_VERSION не піднімати, якщо можна обійтись п.5. Якщо без цього ніяк — пояснити в handoff чому.
