# BOT-008 — «Viktoria Shoes» у посиланні на сайт

Модель: Sonnet · рівень: Medium. Малий тікет, лише бот (робот не чіпаємо).

## Що хоче Влад
Зараз у пості бота одним рядком-посиланням іде:
```
🛍 Більше взуття на сайті 👈
```
Має бути два рядки, обидва разом — **одне посилання** на `SITE_URL`, рука — вказівник на назву магазину:
```
🛍 Більше взуття на сайті
Viktoria Shoes 👈
```
Інше в підписі не змінюється: «Пишіть сюди 👉 @…», порожні рядки (BOT-007), «Додаткові фото в коментарях ⬇️».

## Що зробити
1. `src/shafa/bot/core.py`: `SITE_TEXT = "🛍 Більше взуття на сайті\nViktoria Shoes 👈"`. Оновити docstring модуля (BOT-006/007 → BOT-008).
2. `caption_entities`: одна `text_link` сутність на обидва рядки (offset першого рядка, length = рядок1 + 1 + рядок2 у UTF-16). Перевірити, що сутність не захоплює сусідніх рядків.
3. Прибирання службових рядків — новий рядок теж службовий:
   - `src/shafa/rules.py`: `SHOP_LINE = ^\s*viktoria\s+shoes\s*(?:👈\s*)?\W*$` (без регістру); додати в `without_service_lines`.
   - `src/shafa/bot/core.py`: у `compose` (прибирання з пересланого поста) і в місці ~рядок 1234 — так само, як `SITE_LINE`.
   - Старий формат «🛍 Більше взуття на сайті 👈» (один рядок) теж має й далі прибиратися — старі пости в каналі.
4. `SHAFA_SITE_BUTTON=ні` → обох рядків немає.
5. Уже опубліковані пости не редагувати. RULES_VERSION не піднімати.

## Тести
- Підпис нового поста: точний текст як вище; одна сутність сайту на 2 рядки, правильні offset/length (емодзі = 2).
- `without_service_lines` / `clean_description` / опис для сайту: прибирає і новий двохрядковий блок, і старий однорядковий. Опис для Шафи/сайту — без «Viktoria Shoes».
- Пересланий пост, що вже містить новий блок, — блок не дублюється.
- Довжина підпису (тест ~рядок 675 `test_bot_core.py`) — оновити.
- `SHAFA_SITE_BUTTON=ні` — без обох рядків.
