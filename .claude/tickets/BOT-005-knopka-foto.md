# BOT-005 — третя кнопка «📷 Більше фото» (коментарі)

Рішення Влада 19.10. Причина: Telegram ховає «Коментарі / Leave a Comment» під постом, якщо в нього є inline-кнопки (перевірено на пості 7013 — на телефоні коментарів не видно). Покупці не бачать альбом.

## Що зробити
1. Під постом бота ПЕРШИМ рядком — URL-кнопка «📷 Більше фото», далі «💬 Запитати про цю пару», «🛍 Більше взуття на сайті».
2. Посилання відкриває тред коментарів поста. Канал з публічним ім'ям (той самий `getChat`, що для «Запитати»): `https://t.me/<ім'я>/<номер_поста>?comment=<id першого фото альбому в групі обговорення>`; без імені — `https://t.me/c/<id>/<номер>?thread=<forwarded_id>`. Перевір документацію t.me-посилань; у handoff — точний формат і чому.
3. Кнопка з'являється лише коли альбом коментарів `done` (до того — дві кнопки, як зараз). Після `done` — `editMessageReplyMarkup` з трьома кнопками (той самий механізм повторів, «not modified» — успіх). Фото < 2 — кнопки нема.
4. Id потрібних повідомлень (forwarded_id / перше фото альбому) — зберегти. db.py змінювати НЕ можна без погодження: якщо потрібна колонка — зупинись і напиши Архітектору, що саме і чому (міграція має бути безпечною для живої бази пілоту).
5. Пости, вже опубліковані ботом без цієї кнопки (з 19.10, наприклад 7013): одноразово дописати кнопку. Як отримати id коментаря для них — запропонуй (напр. команда `python -m shafa bot --add-photo-button <post_id>` або автоматично при старті). Без пересилань і повторних постів у канал.
6. Перемикач `SHAFA_PHOTO_BUTTON` (типово увімкнено), як інші.
7. Тести: порядок кнопок, URL обох форматів, кнопка лише після `done`, повтори при помилці, старі пости.
