# BOT-001 — код готовий, чекає бота й тестового каналу від Власника (живий прогін)
**Гілка:** `feature/BOT-001-bot` (не запушена) · **PR:** немає · **Перевірки:** `make ci` зелений (873). Запитів до Telegram — 0.
1. Фаза 0 (коміт `fe8ffa7`) закрита рішеннями D1–D8.
2. Зроблено:
   - `bot/telegram.py`: Bot API через `httpx2==2.13.1` (тепер закріплений); кожна помилка — своя, без адреси й токена. Тест перевіряє 11 видів помилок, повний traceback і маскування токена, якщо Telegram повторить його в описі.
   - `bot/core.py`:
     - лише приватні чати її й Власника, решту ігнорує мовчки; той самий `update_id` удруге нічого не робить;
     - усе, що прийшло за 2 хв від останнього повідомлення, — одна чернетка; прев'ю після 3 с тиші;
     - без фото — «Надішли фото», без тексту — «Надішли текст»; > 10 фото і текст > 1024 (рахунок як у Telegram, UTF-16) — зрозуміла відмова;
     - «Опублікувати / Скасувати», прев'ю дійсне 24 год; стара кнопка й кнопка під час дописування нічого не публікують;
     - «публікую» записується до `sendPhoto`; невизначена відповідь → `uncertain`, Власнику, без повтору; після падіння `recover()` переводить такі чернетки в `uncertain`;
     - фото файлом → оригінал у папку, у канал — копія (поворот за EXIF, ≤ 10 МБ); PNG → JPG; HEIC тощо — відмова (D4);
     - підпис — як у її постах; папка `<номер>` / `<номер>-бот` (D8); пост у `posts` (`bot`, дата каналу).
   - `bot/run.py` і `python -m shafa bot [--check]`: права в каналі на старті, довге опитування, замок «один бот», `bot_status`.
   - Екран: «Бот: працює / вимкнений / зупинився: …», «Запустити бота»; `ui` запускає бота сам, якщо є токен.
   - Схема 7: `bot_updates`, `bot_drafts`, `bot_draft_parts`, `bot_status`.
3. Відхилення:
   - Канал публікації — окреме налаштування `TELEGRAM_BOT_CHANNEL_ID`, а не `TELEGRAM_CHANNEL_ID` (з нього беруться назви папок). Так її канал не стане каналом бота випадково.
   - Без тексту прев'ю теж не показується («Надішли текст»).
   - Бот лишається працювати після закриття екрана, як і робот.

5. TD: нові TD-023 (HEIC), TD-024 (бот лише при ввімкненому ноутбуці), TD-025 (форматування), TD-026 (альбом — лише тестами за документацією).
**Що потрібно — Власник, по одній дії:**
1. Telegram → @BotFather → `/newbot` → ім'я й username бота → скопіюй токен (нікому не надсилай).
2. Створи **приватний тестовий канал** (не її).
3. Додай бота в тестовий канал адміністратором з правом «Публікувати повідомлення».
4. У `.env` у корені проєкту допиши (тихо, як ключ ШІ): `TELEGRAM_BOT_TOKEN=…`, `TELEGRAM_BOT_CHANNEL_ID=…` (id тестового каналу; видно в посиланні на будь-який пост: `t.me/c/<id>/…`), `TELEGRAM_OWNER_CHAT_ID=…` (свій id; якщо не знаєш — після кроку 1 напиши боту «/start», і я прочитаю id з оновлень, коли дозволиш).
5. Скажи «бот готовий» — далі живий прогін у тестовому каналі (`bot --check`, потім 3 пости: одне фото, альбом із 5, фото файлами).
