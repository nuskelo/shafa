3. **Ітерація 2** (рішення Власника):
   - `bot/hashtag.py` — хештег, як ставить вона. Звірено з Експортом: збіг 2296 з 2347 постів (97,8%). З 46 розбіжностей 29 — рішення «ідуть на A-B → B», решта — її поодинокі винятки.
   - Сумки, гаманці, рюкзаки, ремені → `#VS_сумки`; інше — без хештега; уже є — не дублює.
   - Взуття без розміру або розмір поза 15–50 → «Не можу зрозуміти розмір…», прев'ю не показує. Відповідь чекає 10 хв (звичайне вікно — 2 хв).
   - Підпис: текст → хештег (окремий рядок) → порожній рядок → «Пишіть сюди 👉 @…» → порожній рядок → «Всі фото в коментарях ⬇️» (лише якщо фото ≥ 2).
   - Прев'ю — фото-картинкою з тим самим підписом, що піде в канал (файл завантажується як фото).
   - Коментарі: фото ≥ 2 → альбом усіх фото відповіддю на пересланий у групу пост. «Надсилаю» записується до відправки, без повторів. Пересланого поста немає 2 хв → їй «фото ще не додались», Власнику тривога; альбом додається, коли пост прийде (до 24 год), далі — «додай руками». Після падіння «надсилаю» → Власнику, без повтору.
   - Старт: у каналу є група обговорення, бот — її адмін, учасники писати не можуть (`permissions.can_send_messages = false`). Інакше бот не стартує й пояснює.

1. «Shafa тест» → назва каналу → **Керування каналом → Обговорення** → «Додати групу» → **створити нову групу** (напр. «Shafa тест — коментарі») → підтвердити прив'язку.
2. Відкрий нову групу → назва → **Керування групою → Дозволи** → вимкни **«Надсилати повідомлення»** для учасників → збережи.
3. У групі → **Адміністратори → Додати адміністратора** → знайди @shafa_test2_bot → права за замовчуванням → збережи.
