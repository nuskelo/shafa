1. Фаза 0 (`218dfc7`) → рішення D1–D7.
2. Зроблено (подробиці — в описі PR):
   - **Запуск без вікна:** `pythonw` більше не падає (`__main__.py`); вивід іде в `app.log`.
   - **`.env`** — у теці даних, права лише її користувачу (`icacls` / `0600`); старий переїжджає один раз сам.
   - **Місця:** робочий стіл — з Windows; Головна папка — поза OneDrive; OneDrive розпізнається.
   - **Програма з ярлика** (`app`): один екземпляр, бот у фоні, «Вийти»; `quit` для оновлення.
   - **Майстер** `setup`: секрети вводяться приховано; ШІ перевіряється безкоштовно, бот — наживо; вхід на Шафу; ярлики.
   - **«Налаштування»** без секретів; **«Завантажити експорт каналу»** (TD-021).
   - **Збірка на Mac:** вбудований Python 3.12.10, 21 залежність з контрольними сумами (TD-005), власна іконка (вішак).
   - **Встановлення/оновлення:** замінюється лише `app`, відкат при помилці.
   - **CI `windows-package`** (нова задача, дозвіл D3): збірка, встановлення в теку з кирилицею, `pythonw`, екран на 127.0.0.1, бот і робот не стартують, «Вийти», журнал без помилок.
   - **Інструкція:** `docs/install-windows.md`.
3. Відхилення:
   - `SHAFA_DATA_DIR` — лише змінна середовища (`.env` сам лежить у теці даних).
   - «Вийти» роботу лише дає «Стоп» — він допише товар; вбивати посеред кліку небезпечно.
   - **На Mac Власника** перша команда після мержу перенесе `.env` з кореня проєкту в `~/Library/Application Support/shafa/.env` (D5).
