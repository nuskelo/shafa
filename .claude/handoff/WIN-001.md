   - **HYP-1 → рекомендація (а): вбудований Python + наш пакет у теці + ярлик на `pythonw.exe`.**
     - (а) Права адміна не потрібні; «(almost) fully isolated from the user's system»; `pythonw.exe` є в пакеті, без консолі. pip і tkinter у пакеті немає — нам і не треба: колеса ставимо при збиранні. Оновлення — замінити теку. Exe підписані PSF — менше шансів на блок Defender (UNKNOWN без її ноутбука).
     - (б) PyInstaller: exe без підпису часто блокує Defender, Playwright пакувати складно — не раджу.
     - (в) Повний інсталятор + venv: без адміна теж можна (`InstallAllUsers=0`), але більше кроків, PATH і псевдонім Microsoft Store плутають — запасний варіант.
   - **DRIFT (версія):** останній Python 3.12 з Windows-збірками — **3.12.10 (08.04.2025)**; новіші 3.12 виходять лише вихідним кодом. Ризик невеликий: сервер лише на 127.0.0.1.
   - **HYP-2 VERIFIED:** усі 21 залежність мають колеса `cp312-win_amd64`/`py3-none-any` з хешами (перевірено `pip install --dry-run --platform win_amd64 --python-version 3.12 --report`; Playwright — `playwright-1.63.0-py3-none-win_amd64.whl` з драйвером). Отже, збірка й закріплення з хешами (TD-005) можливі **на Mac** без змін `.github/`. Перевірити пакет на чистому Windows без зміни CI неможливо — потрібен job у `windows-tests`.
   - **HYP-3:**
     - `data_dir()` на Windows уже `%LOCALAPPDATA%\shafa` (`config.py:58`) — VERIFIED.
     - **DRIFT:** `.env` читається з кореня проєкту (`config.py:10`); у встановленій програмі це тека програми, тож оновлення його стерло б. Перенести в теку даних.
     - **OneDrive** (UNKNOWN без її ноутбука): «Робочий стіл» часто перенесено в `OneDrive\Desktop`. Тоді `Робочий стіл\Шафа` з тисячами фото синхронізується в хмару (квота), а файли «лише в хмарі» докачуються при читанні. Шлях до робочого столу брати з Windows (Known Folder), не з `~\Desktop`.
   - **HYP-4:**
     - **DRIFT:** `__main__.py:505` викликає `sys.stdout.reconfigure(...)`, а під `pythonw` `sys.stdout` — `None` → падіння на старті. Виправити.
     - Бот і робот уже запускаються через `sys.executable` без вікна (`control.py:156,165`) — під `pythonw` теж без вікна.
     - Один екземпляр: замок ОС `ui.lock` (як у робота) + порт у теці даних. Другий клік на ярлик відкриває той самий екран у браузері.
     - Закриття браузера сервер не гасить; «Вийти» на екрані гасить сервер і бота.
   - **HYP-5:**
     - Майстер у консольному вікні (`python.exe`): секрети вводяться приховано (`getpass`) і записуються в `%LOCALAPPDATA%\shafa\.env`. Тека в профілі користувача (доступ: вона, SYSTEM, адміністратори — штатно, UNKNOWN без її ноутбука); пропоную ще звузити `icacls` до неї.
     - Перевірки майстра: ключ ШІ — `models.list` (безкоштовно); бот — наш `bot --check`; Шафа — `robot --login`, пароль вона вводить сама.
     - Окремий ключ ШІ і **окремий робочий бот** — Власник створює заздалегідь.
