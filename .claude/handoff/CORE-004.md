   - `fill.py`: `retry` («ШІ, спробуй ще раз», без кешу, правки лишаються); `fill` по одній не бере Картки з пакета.
   - CLI: `fill --batch [--limit]`, `--collect`, `--estimate`.
   - Екран: панель ШІ («Оновити» = scan без Експорту → збір → пакет у фоні; «Готові / Чекають відповіді / Чекають 7 днів»; збір готового раз на 3 хв, поки є незібрані); «ШІ, спробуй ще раз» у Картці `review`; одна робота ШІ за раз (замок).
   - TD-016: фото опублікованих — з «Опубліковано».
