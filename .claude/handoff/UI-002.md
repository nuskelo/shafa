Mac: `start_new_session=True` (POSIX `setsid`), інакше Ctrl+C у вікні сервера перерве й робота. Windows: `creationflags=CREATE_NO_WINDOW | CREATE_NEW_PROCESS_GROUP` (docs 3.12, «Added in version 3.7»). Наживо на Windows не перевірено (TD-010) → тест у `windows-tests`.
     **Замок:** перевіряти «живий» за PID не можна — на Windows `os.kill(pid, 0)` «unconditionally killed by the TerminateProcess API» (docs `os.kill`). Пропоную файловий замок у теці даних: `fcntl.flock` (POSIX) / `msvcrt.locking(LK_NBLCK)` (Windows). Microsoft (`LockFile`, Remarks): «If a process terminates with a portion of a file locked … the locks are unlocked by the operating system» → після падіння замок не «зависає»; сон — процес живий, замок тримається (так і треба). Що `msvcrt.locking` іде через `LockFile` — UNKNOWN (не читав джерел CRT) → тест у `windows-tests`: дочірній процес бере замок, його вбивають, замок вільний.
