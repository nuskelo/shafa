# Концепція: «Шафа-помічник»

> Версія 1 · 12.10.2026 · Архітектор. Джерело рішень — розмова з Власником (Влад) 26.09–12.10.2026.
> Детальний опис для людей: Claude Docs «Шафа-помічник: як усе працюватиме».

## Навіщо

Знайома Власника (продавчиня, далі **Продавчиня**) продає вживане й нове взуття, сумки, рюкзаки, гаманці й ремені.
Спершу вона публікує товар у Telegram-каналі (1 фото + опис), потім вручну переносить на Shafa.ua (до 10 фото, назва, розділ, поля).
Ручне перенесення забирає час, тому борг — сотні постів, яких немає на Шафі.

**Програма** бере текст поста й фото з папки, ШІ заповнює всі поля, Продавчиня перевіряє й схвалює, а робот у браузері публікує схвалене на Шафі.

## Для кого

- **Продавчиня** — щодня: дає фото, перевіряє картки, натискає «Старт». Не технічна людина; Windows-ноутбук, Chrome, Telegram Desktop.
- **Власник** — розробляє, встановлює, лагодить віддалено, платить за ШІ.

## Глосарій

| Термін | Значення |
|---|---|
| **Канал** | Telegram-канал Продавчині (`private_channel`, id `2394827824`). |
| **Пост** | Повідомлення каналу з товаром. Має **номер** (message id, напр. 1342), дату й текст. |
| **Експорт** | `result.json` з Telegram Desktop (лише текст), джерело текстів старих постів. Зроблено 05.10.2026, пости 2…6867. |
| **Головна папка** | Папка на комп'ютері Продавчині з папками товарів (розташування ще не вирішене). |
| **Папка товару** | Підпапка з фото одного товару. Назва — номер поста (`1342`) **або** id каналу + номер (`23948278241342`). Папка = «хочу цей товар на Шафі». |
| **Картка** | Товар у програмі: пост + фото + поля для Шафи + статус. |
| **Бланк** | Поля, заповнені ШІ (назва, розділ, колір, …). |
| **Розділ** | Категорія Шафи (напр. «Жіночий одяг / Взуття / Кросівки»). **Після публікації змінити не можна.** |
| **Екран перевірки** | Локальна веб-сторінка з вкладками і картками. |
| **Робот** | Автоматизація браузера (Playwright), що заповнює форму «Додати товар» на Шафі. |
| **Сесія** | Один запуск робота від «Старт» до «Стоп»/кінця черги/ліміту. |
| **Ліміт доби** | Не більше 30 публікацій за календарну добу сумарно (налаштовується). |
| **Етап 1** | Старі пости: папки створює Продавчиня вручну, тексти з Експорту. |
| **Етап 2** | Нові пости: Продавчиня надсилає Боту текст + фото, Бот публікує пост у Канал і створює папку. |
| **Бот** | Telegram-бот Продавчині: публікує в Канал, створює папки, нагадування, звіти. |

## Що робить перша версія (MVP)

1. Знаходить папки товарів у Головній папці, зіставляє з постами (Експорт або Бот).
2. Для нових постів чекає 7 днів від дати поста (Етап 1 — без очікування).
3. ШІ (Claude API, пакетний режим) заповнює бланк за правилами нижче; сумнівне — жовта позначка.
4. Екран перевірки: вкладки На перевірку / Схвалені / Опубліковані / Проблеми / Сесії / Архів; редагування в картці; «Схвалити», «Відхилити» (в архів на 7 днів), «ШІ, спробуй ще раз», «Скасувати схвалення».
5. Кнопка «Старт» → робот публікує схвалені (найстаріші першими), паузи 1–3 хв, ≤ 30 на добу; Пауза / Стоп (дописує поточний товар).
6. Звіт сесії: вкладка «Сесії» + Бот (Продавчині коротко, Власнику з помилками й скріншотами).
7. Папка опублікованого → «Опубліковано», видалення через 3 дні.
8. Бот (Етап 2): публікує пост (перше фото + текст + підпис), зберігає всі фото в папку; нагадування; тривоги Власнику; журнал подій фону (ШІ, робот, довідники — «Детально» / «Лише важливе», `/detali`); щотижневі витрати на ШІ.

## Правила заповнення (коротко; повністю — `docs/rules.md`)

- **Ціна:** Telegram × 1,15 → вгору до десятка → 450–500 → 501; 950–1000 → 1001.
- **Назва:** `[Нові] [Шкіряні/Замшеві] [термо] тип бренд [модель] [оригінал] [з мембраною gore-tex] N розміру [стан]`; без статі й кольору.
- **Опис:** текст поста без першого речення, ціни, підпису, @нікнеймів, посилань, хештегів; у кінці «Ідеальний стан, без дефектів.» / «Стан нових, без дефектів.».
- **Стан:** «новий / в стані нових / в новому стані» → Новий; інакше Ідеальний.
- **Розділ:** ШІ за фото + розміром; дитяче завжди з поділом дівчатка/хлопчики/малюки; аксесуари — «Для жінок».
- **Розмір:** Європейський; «вказаний X, ідуть на Y» → Y.
- **Колір:** 1–2 з 32 варіантів Шафи; 3+ → Різнокольоровий.
- **Матеріал / підкладка / мембрана / довжина устілки / сезон / стиль / тип** — як у її поточних оголошеннях (див. `docs/rules.md`).
- **Ключові слова:** 4–6, генерує ШІ.
- **Фото:** порядок як у папці (головне вже перше, бірки останні); ШІ перевіряє; 4:3 і 3:4 — норма.

## Чого НЕ робимо (перша версія)

- Не публікуємо без схвалення людини. Не публікуємо за розкладом — лише кнопкою.
- Не відстежуємо видалення/редагування постів у каналі після збереження.
- Не знімаємо продане з Шафи автоматично.
- Немає схвалення з телефона, масового схвалення, Instagram, автооновлення.
- Не зберігаємо паролі Шафи: робот використовує сесію окремого профілю Chrome, куди Продавчиня входить сама.
- Немає сервера: усе працює на ноутбуці Продавчині.

## Середовище

- **Продакшн:** ноутбук Продавчині, Windows, Chrome, ~1 ГБ вільного місця, слабкий. Запуск ярликом.
- **Розробка:** Mac Власника. Код має бути кросплатформним (шляхи, кодування, кирилиця в назвах).
- **Зовнішні сервіси:** Telegram Bot API, Claude API (найновіша Sonnet, Batch), shafa.ua (лише через браузер; імпорту з файлу немає).

## Критерії готовності першої версії

1. 20–30 реальних папок Етапу 1 → картки з полями; Продавчиня погоджується з ≥ 90% полів без правок; розділ правильний у всіх, де немає жовтої позначки.
2. Робот публікує 1 тестове оголошення з дозволу Власника, далі сесію з 10 — без ручного втручання, з коректним звітом.
3. Бот публікує пост у канал і створює папку (Етап 2).
4. Програма запускається ярликом на Windows-ноутбуці Продавчині.
