# Правила заповнення картки

> Версія 1 · 12.10.2026 · Архітектор. Джерела: рішення Власника (06–12.10), форма Шафи (`research/shafa-form.md`), аналіз її 1285 оголошень (`research/her-listings-analysis.md`).
> **Хто робить:** «код» — детерміновано, з тестами; «ШІ» — Claude за інструкцією; «код+ШІ» — ШІ пропонує, код перевіряє.

## 1. Вхід

- **Папка товару:** назва `^\d+$`. Якщо довжина > 10 і починається з `2394827824` — номер поста = решта цифр; інакше вся назва = номер поста.
- **Фото:** лише `.jpg/.jpeg` (без урахування регістру), ≤ 10 шт., кожне ≤ 10 МБ. Поворот брати з EXIF (orientation). Пропорції 4:3 і 3:4 (±2%) — норма; інші → «Проблеми».
- **Текст поста:** Етап 1 — з `result.json` (поле `text` може бути рядком або списком шматків). Етап 2 — з повідомлення Боту.
- Пост без ціни або без поста з таким номером → «Проблеми».

## 2. Ціна (код)

```
p = ціна_з_тексту * 1.15          # остання «NNN грн» у тексті
p = ceil(p / 10) * 10             # вгору до десятка
if 450 <= p <= 500:  p = 501
if 950 <= p <= 1000: p = 1001
```
Приклади: 600→690; 655→760; 420→490→501; 850→980→1001; 1200→1380.
Дві ціни (стара закреслена + нова) → нова (остання).

## 3. Очищення опису (код)

Прибрати: перше речення (воно = назва), ціну (`\d+\s*грн`), підпис `Пишіть сюди 👉 @viktoriaviktoriatg`, будь-які `@нікнейми`, посилання, телефони, хештеги (`#VS_42_розмір`). Додати в кінець: «Ідеальний стан, без дефектів.» (стан Ідеальний) або «Стан нових, без дефектів.» (стан Новий), якщо в тексті вже немає речення про стан.

## 4. Стан (код)

«новий», «нові», «нова», «в стані нових/нового», «в новому стані» → **Новий**; інакше → **Ідеальний**.

## 5. Назва (ШІ, код перевіряє довжину й відсутність контактів)

`[Нові] [Шкіряні/Замшеві] [термо] <тип> <бренд> [модель] [оригінал] [з мембраною gore-tex] <N> розміру [в ідеальному стані / у відмінному стані / в стані нових]`
Без статі й кольору. ≈ перше речення поста + розмір. Приклади з її профілю: «Шкіряні черевики pavers 42 розміру», «Кросівки adidas оригінал в ідеальному стані 44 розмір», «Зимові термо черевики lowa з мембраною gore-tex 37 розміру в ідеальному стані», «Шкіряна сумка caroll paris в новому стані».

## 6. Розділ (ШІ за фото + розміром; код перевіряє, що шлях є в дереві Шафи)

- Взуття: `Жіночий одяг / Взуття / <тип>`, `Чоловічий одяг / Взуття / <тип>`, `Дитячий одяг / Для дівчаток | Для хлопчиків | Для малюків / Взуття / <тип>`.
- Сумки/рюкзаки/гаманці/ремені: `Аксесуари / Сумки та рюкзаки | Гаманці та портмоне | Ремені та пояси / <тип>` + поле «Стать: Для жінок».
- Підказка за розміром (з її даних): ≤ 34 — дитяче; 35–36 — дитяче або жіноче (фото); 37–40 — жіноче; 41–42 — жіноче або чоловіче (фото); ≥ 43 — чоловіче. ≤ 22 — «Для малюків».
- Невпевненість → жовта позначка. **Розділ після публікації не змінюється.**

## 7. Розмір (код+ШІ)

Система «Європейський». «Вказаний X, ідуть на Y» → Y. Дробові 0,5 — як є. Дитячий список 22–41, жіночий 34–46, чоловічий — перевірити у формі (Фаза 0 CORE-тікета).

## 8. Колір (ШІ)

1–2 з 32 варіантів Шафи; 3+ помітних кольори → «Різнокольоровий».

## 9. Матеріали, мембрана, устілка, додаткові поля

| Поле | Хто | Правило |
|---|---|---|
| Матеріал (верху) | ШІ | Із тексту: Шкіра / Замша / Нубук / Текстиль (можна кілька). Для сумок список Шафи: Шкіра, Штучна шкіра, Текстиль, Нейлон, Поліестер, Бавовна. Немає в тексті — порожньо |
| Матеріал підкладки | ШІ | Із тексту: Хутро, Фліс, Вовна, Шкіра, Текстиль… |
| Мембрана | код+ШІ | `gore-tex` → «Gore-Tex»; будь-яка інша мембрана → «Є»; немає → не заповнювати |
| Довжина устілки | код | Усі заміри з тексту + сусідні значення з кроком 0,5 між мін і макс; одиночне значення X,5 → X і X,5 (як у неї). Діапазон Шафи 22,5–31 |
| Сезон / Стиль / Тип / Категорія «Для підлітків» | ШІ | Лише коли очевидно |
| Бренд | ШІ | Із тексту, зі списку Шафи. Немає в списку → жовта позначка (правило — відкрите питання) |
| Ключові слова | ШІ | 4–6: тип; тип+стать; тип+бренд; тип+розмір; за потреби сезон або яскравий колір |

## 10. Фото (код+ШІ)

Порядок = порядок імен файлів у папці (у неї головне вже перше, бірки останні). ШІ перевіряє: перше — взуття боком, носком вліво (сумки — файл «1» або фото спереду); фото бірок — у кінці (може бути 2). Інакше — переставити і жовта позначка.
