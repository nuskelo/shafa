# Запуск «Шафа-помічник» на Mac Власника (тиждень пілота)

Для Власника. Усе робиться з терміналу в теці проєкту (`~/shafa`). Це **окрема тека даних** `~/shafa-viktoria`:
не змішується з тестовою `~/Library/Application Support/shafa`. Її дані виконавець (Claude) не розпаковує й
програму не запускає — це робиш ти.

## Перед усім: два процеси на одному акаунті не можна

На її ноутбуці програма на цей час має бути **вимкнена** («Вийти» на екрані — зупиняє екран і бота).
Інакше буде **два боти** з одним токеном (Telegram не віддає оновлення обом — вони «б'ються»)
і **два роботи** на одному акаунті Шафи (подвійні публікації). Поки йде пілот на Mac — на ноутбуці лише «Вийти».
Назад — навпаки: на Mac «Вийти», потім вмикати на ноутбуці.

## 1. Тека даних

```sh
cd ~/shafa
export SHAFA_DATA_DIR="$HOME/shafa-viktoria"
mkdir -p "$SHAFA_DATA_DIR"
```

→ Змінну треба ставити **в кожному новому вікні терміналу** (або додай рядок `export …` у `~/.zshrc`).
Вона єдина, що вказує, де дані: без неї програма візьме тестову теку.
Перевірка: `.venv/bin/python -c "from shafa import config; print(config.data_dir())"` → має вивести
`/Users/<ти>/shafa-viktoria`.

## 2. Її база й фото старих постів

Архів `~/Desktop/ChatExport_2026-10-15/bot-run.zip` містить її `shafa.sqlite` і теку `borh/`.

```sh
mkdir -p ~/shafa-viktoria-unzip && unzip -q ~/Desktop/ChatExport_2026-10-15/bot-run.zip -d ~/shafa-viktoria-unzip
ls ~/shafa-viktoria-unzip | head -n 20
```

→ Знайди в списку `shafa.sqlite` і `borh`. Скопіюй (не перемісти) у теку даних:

```sh
cp ~/shafa-viktoria-unzip/shafa.sqlite "$SHAFA_DATA_DIR/shafa.sqlite"
cp -R ~/shafa-viktoria-unzip/borh "$SHAFA_DATA_DIR/borh"
cp "$SHAFA_DATA_DIR/shafa.sqlite" "$SHAFA_DATA_DIR/shafa.sqlite.до-оновлення"
```

→ Остання команда — запасна копія: при першому відкритті база сама оновиться до версії 11 (CORE-008),
назад дороги немає. Якщо шляхи в архіві інші — скажи Архітектору, що показав `ls`.

## 3. Налаштування (майстер)

```sh
.venv/bin/python -m shafa setup
```

→ Майстер питає по черзі: Головну папку (Enter — типова; на Mac для старих постів вона майже не потрібна),
ключ ШІ, токен бота, id каналів і чатів. **Секрети вписуєш ти** (на екрані не показуються); у чат їх не надсилай.
Усе збережеться в `~/shafa-viktoria/.env` (права лише твої). Питання «Відкрити вікно входу на Шафу?» —
відповідь «ні», вхід у кроці 4.

Важливо для пілота:
- `TELEGRAM_BOT_CHANNEL_ID` — **спершу тестовий канал**; її живий канал — лише з окремого дозволу.
- `SHAFA_SITE_SEND` не вмикай (типово «ні» — на сайт нічого не йде).
- Ярликів майстер на Mac не створює (це лише Windows) — програму запускають командою нижче.

## 4. Вхід на Шафу (пароль вводить вона)

```sh
.venv/bin/python -m shafa robot --login
```

→ Відкриється вікно Chrome з профілем робота (`~/shafa-viktoria/robot-profile`). **Вона сама** вводить логін і
пароль. Потім закрити вікно (або кнопка «Я увійшов — закрити вікно» на екрані). Потрібен встановлений
Google Chrome (`/Applications/Google Chrome.app`); окремо нічого ставити не треба.

## 5. Запуск програми

```sh
.venv/bin/python -m shafa app
```

→ Відкриється браузер з екраном перевірки; бот стартує сам (якщо є токен), журнал бота — `bot-run.log`,
робота — `robot-run.log` у `~/shafa-viktoria`. Зупинити: кнопка «Вийти» на екрані або `.venv/bin/python -m shafa quit`.
Ще раз `app` при запущеній програмі лише відкриє той самий екран.

Робот публікує **наживо** лише з кнопки «Старт» і лише з дозволу. Спершу — «Перезаповнити не перевірені»
на панелі ШІ (покаже «≈N карток, ≈$X» до запуску), перегляд, і тільки потім публікація.

## Якщо щось пішло не так

- Екран показує порожню базу → `SHAFA_DATA_DIR` не виставлена в цьому вікні терміналу (крок 1).
- «Робот уже працює» (код 2) → у фоні вже є процес робота; «Стоп» на панелі або `quit`.
- Повернутися до чистого стану: зупини програму, поверни `shafa.sqlite.до-оновлення` на місце `shafa.sqlite`
  (дані, додані після копії, пропадуть).
