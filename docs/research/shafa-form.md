# Форма «Додати товар» на Шафі — що там є

> Перевірено 12.10.2026 у браузері (акаунт Влада), сторінка https://shafa.ua/uk/new. Нічого не публікувалось.

## Імпорт
- Кнопка «Імпортувати товари» веде на Google-форму-опитування. **Імпорту з файлу поки немає** («ваші товари поки не імпортуються на Шафу»). Отже — робот, що заповнює форму.

## Загальні поля (для всіх)
| Поле | Обов'язкове | Що всередині |
|---|---|---|
| Фото | так | до 10 (спершу 5 слотів + «Завантажте ще 5»). Підказки слотів: головне фото в повному розмірі / зворотня сторона / інші ракурси / бірка або етикетка / дефекти. Порядок міняється перетягуванням |
| Відео | ні | посилання YouTube |
| Назва (українською) | так | Підказка для взуття: **«Категорія + стать + бренд + характеристики (колір, розмір, довжина устілки, матеріал)»**. Приклад Шафи: «Кросівки жіночі Puma Club 5v5 38 класичні на шнурівці Білі» |
| Розділ | так | дерево категорій (нижче) |
| Стан | так | Новий / Ідеальний / Дуже хороший / Хороший / Задовільний |
| Бренд | **ні** | пошук зі списку; якщо бренду нема — «Додати бренд: X» (видно після модерації) |
| Опис (українською) | ні | для взуття підказка: довжина устілки, ширина устілки, сезон/матеріал/утеплювач, особливості, дефекти |
| Ключові слова | ні | через кому або Enter |
| Ціна | — | «Оплата … грн» або «Подарунок» |
| Кнопка | — | «Додати річ» |

## Поля, що з'являються після вибору розділу

### Жіноче взуття (на прикладі «Кросівки»)
- **Розмір*** — система Європейський / Український / Американський; 34–46 з кроком 0,5, «Інший», «One size». Для вживаних — до 2 опцій. «Розмір, що зазначений на бірці».
- **Колір*** — до 2 відтінків із 32: Білий, Сріблястий, Бежевий, Сірий, Жовтий, Золотистий, Помаранчевий, Рожевий, Червоний, Бірюзовий, Синій, Хакі, Зелений, Фіолетовий, Коричневий, Чорний, **Різнокольоровий**, Блакитний, Бордовий, Салатовий, Персиковий, Бузковий, Кораловий, Гірчичний, Фуксія, М'ятний, Малиновий, Молочний, Графітовий, Оливковий, Нюдовий, Прозорий.
- Додаткові (необов'язкові): Зроблено в Україні; Особливості моделі (Високі / На липучках / На платформі / Утеплені); Сезон (Весна / Демісезон / Зима / Літо / Осінь); Тип підошви (Каблук / Пласка / Платформа); **Мембрана (Gore-Tex / Є / Немає)**; **Матеріал** (список нижче); Призначення (для бігу, для повсякденного носіння, …); Принт; **Довжина устілки** (22,5–31 см, крок 0,5).
- **Матеріал (взуття), 30 варіантів:** Атлас, Бавовна, Велюр, Гіпюр, Гума, Джинс, **Замша**, Каучук, Крослайт, Лакована шкіра, Лакована штучна шкіра, Нейлон, **Нубук**, Оксамит, Повсть, Поліестер, Поліуретан, Сатин, Силікон, Синтетика, Сітка, Текстиль, Трикотаж, Фетр, Хутро, **Шкіра**, Штучна замша, Штучна шкіра, Штучне хутро, Штучний нубук.

### Дитяче взуття (на прикладі «Для дівчаток → Черевики»)
- **Розмір*** — Європейський / Американський; 22–41 з кроком 0,5, «Інший».
- **Колір*** — ті самі 32.
- Додаткові: Висота виробу; **Категорія (Для дітей / Для підлітків)**; Сезон; Застібка (Без застібки / Еластичні шнурки / Замок / Липучка / Шнурівка); Підбор; Стиль; Супінатор; Мембрана (Gore-Tex / Є / Немає); **Матеріал верху**; **Матеріал підкладки**; Довжина устілки.

### Рюкзак («Аксесуари → Сумки та рюкзаки → Рюкзаки»)
- **Розміру немає.** Колір* — ті самі 32.
- Додаткові: Вид; Застібка; Розмір (Великий / Маленький / Середній); Спинка; **Стать** (Для жінок …); Стиль; **Матеріал — лише 6: Бавовна, Нейлон, Поліестер, Текстиль, Шкіра, Штучна шкіра (замші немає)**; Об'єм, л; Особливості; Улюблені персонажі; Принт.

## Ще не перевірено
- Завантаження фото й галочка «фото зроблені самостійно» (потрібен реальний файл).
- Що відбувається після «Додати річ» (екран успіху, дубль) — тільки на першому тесті з дозволу.
- Поля для сумок «Сумки», гаманців, ременів, чоловічого взуття (очікуємо схожі).
