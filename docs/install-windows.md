# Встановлення «Шафа-помічник» на її ноутбук (Windows)

Для Власника, на день встановлення. По одній дії; після кожної — що має вийти.
Права адміністратора не потрібні. Автозапуску з Windows немає — лише ярлик.

## Заздалегідь, удома

1. **Пакет програми.** На Mac у теці проєкту: `.venv/bin/python ops/build_windows.py build`.
   → З'явиться `dist/shafa-windows-<версія>.zip` (≈ 70 МБ). Скопіюй його на флешку або в хмару.
2. **Ключ ШІ для неї.** console.anthropic.com → API Keys → Create Key → назва «Шафа — Вікторія».
   → Ключ показують один раз: збережи в менеджері паролів. **Не надсилай у чат.**
3. **Робочий бот** (не тестовий). Telegram → @BotFather → `/newbot` → ім'я й username.
   → Токен збережи в менеджері паролів.
4. **Свій chat id** — ти його вже знаєш (`TELEGRAM_OWNER_CHAT_ID` з тестів).
5. Візьми з собою: zip, ключ ШІ, токен бота, ключ сайту (якщо вже є), свій chat id. Її пароль від Шафи вводить **вона сама**.

## На її ноутбуці

### 1. Перевірити
1. Відкрий Chrome. → Відкривається (робот працює лише з Chrome).
2. Відкрий Telegram Desktop. → Вона в своєму акаунті.

### 2. Канал і група коментарів (робить вона, ти підказуєш)
1. Її канал → Керування каналом → **Адміністратори** → додати робочого бота → право «Публікувати повідомлення».
   → Бот у списку адміністраторів.
2. Канал → Керування каналом → **Обговорення** → створити нову групу (напр. «Коментарі»).
   → Під постами з'явиться «Коментувати».
3. Нова група → Керування групою → **Дозволи** → вимкнути **«Надсилати повідомлення»**.
   → Покупці не зможуть писати в коментарях.
4. Група → **Адміністратори** → додати робочого бота (права за замовчуванням).
5. Id її каналу: відкрий будь-який пост → «Копіювати посилання» → `https://t.me/c/2394827824/1342`.
   → Число після `/c/` — id каналу (тут `2394827824`).
6. Її chat id: у її Telegram знайди **@userinfobot** → «Start». → Він покаже `Id: …` — запиши число.
   (Цей бот лише показує її номер; нічого не надсилає.)

### 3. Встановити
1. Скопіюй zip на її ноутбук (у «Завантаження»).
2. Правою кнопкою на zip → **«Видобути все»** → «Видобути».
   → Відкриється тека `shafa-windows` з `app` і **«Встановити»**.
3. Двічі клацни **«Встановити»**.
   → Якщо синє вікно «Windows захистив ваш ПК» → «Докладніше» → «Виконати все одно».
   → Чорне вікно: «Встановлено «Шафа-помічник» …», далі сам почнеться майстер.

### 4. Майстер налаштування (у тому ж чорному вікні)
1. «Головна папка…» → натисни **Enter** (перший раз — `C:\Users\<вона>\Шафа`, поза OneDrive;
   повторно — та папка, що вже вибрана).
   → Якщо з'явиться «!!! УВАГА: ця папка в OneDrive» — відповідай «ні» і бери запропоновану.
2. «Ключ Claude API…» → встав ключ **правою кнопкою миші, один раз** → Enter.
   → **Нічого не видно — так задумано.** Ctrl+V у чорному вікні не вставляє (додає зайвий символ),
   кожен правий клік — ще одна копія.
   → «Ключ/токен вставлено з помилкою — встав ще раз» → правий клік один раз → Enter.
3. «Токен робочого бота…» → встав токен → Enter.
   «Ключ сайту Viktoria Shoes (необов'язково…)» → встав ключ сайту → Enter (немає під рукою —
   просто Enter; вписати пізніше — розділ 5б). Теж нічого не видно.
4. Id каналів і чатів — по одному, Enter після кожного:
   канал для бота — **id її каналу** (публікувати в нього — твій дозвіл зараз), канал для назв папок —
   той самий id, її chat id, твій chat id.
5. Чекай перевірок.
   → «Ключ ШІ працює». → «Бот @…: права в каналі є, коментарі — лише вона й бот».
   Якщо інакше — текст підкаже, що виправити в каналі/групі; потім просто запусти «Встановити» ще раз.
6. «Відкрити вікно входу на Шафу?» → «так».
   → Відкриється Chrome: **вона** входить на Шафу своїм логіном і паролем, потім **закриває** вікно.
7. → «Готово». На робочому столі: **«Шафа-помічник»** і **«Шафа — фото товарів»**. Закрий чорне вікно.

### 5. Перший запуск
1. Двічі клацни **«Шафа-помічник»** на робочому столі.
   → Без чорних вікон відкриється браузер з екраном. Угорі панель: «Бот: працює».
2. Клацни ярлик ще раз. → Відкривається той самий екран (друга програма не запускається).
3. Вкладка **«Налаштування»**: ліміти (30 публікацій, $3 на ШІ, 7 днів) — лиши як є.
   **«Старих на день»** — 10 (тиждень 1), **«Нових на день»** — 0, доки нові пости через бота не
   почнуть іти на Шафу; разом не більше 30. Вона міняє їх сама, діє з наступного товару.
4. Там же **«Завантажити експорт каналу»**: Telegram Desktop → її канал → ⋮ → «Експорт історії чату»
   → постав галочку **«Фото»** (для старих постів, розділ 5а), формат **JSON** → «Експортувати».
   → З'явиться тека `ChatExport_<дата>` з `result.json` і `photos`. Вибери цей `result.json`.
   → «Експорт завантажено: постів …».
5. **«Вийти»** (угорі праворуч). → «Програму закрито». Бот теж зупинився.
   Закриття вкладки браузера програму **не** закриває — лише «Вийти».
6. Коли робот публікує, його вікно Chrome **можна згорнути** або закрити іншими вікнами — робот
   працює далі з тією ж швидкістю. Закривати саме вікно робота (хрестиком) не треба — це «Стоп».

### 5а. Старі пости (з одним фото поста)
Старі товари йдуть на Шафу з одним фото — тим, що в пості; папки для них не потрібні.
1. **Список номерів** робиш ти: текстовий файл `старі.txt`, у кожному рядку — номер поста
   (число після `/c/<id каналу>/` у посиланні на пост). Порожні рядки й рядки з `#` — пропускаються.
   Поклади файл поруч із текою експорту. **Порядок рядків — це порядок публікації:** робот бере
   старі зверху вниз (а не за датою поста), і ШІ готує їх у тому ж порядку. Один список на все.
2. Win+R → `cmd` → Enter. У чорне вікно встав (заміни шляхи на свої, лапки лиши) → Enter:
   ```
   "%LOCALAPPDATA%\shafa\app\python\python.exe" -m shafa import-old --export "C:\Users\<вона>\Downloads\Telegram Desktop\ChatExport_<дата>" --list "C:\Users\<вона>\Downloads\Telegram Desktop\старі.txt"
   ```
   → «Створено: N · вже було: N · немає в експорті: N · без фото: N». Номери, яких немає в
   експорті, — нижче списком. Фото скопійовано в теку програми: експорт потім можна видалити.
3. Запустити ще раз з тим самим чи доповненим списком — безпечно: вже завантажені пропускаються,
   дублів немає. **Повторний імпорт з новим списком міняє порядок** ще не опублікованих
   старих (внизу: «порядок оновлено: N»); опубліковані й нові Картки не чіпає.
4. На екрані з'являться Картки «Нові»; далі — як усі: ШІ, перевірка, «Схвалити». Робот бере
   спершу нові, потім старі, кожних — не більше, ніж у «Налаштуваннях». ШІ заповнює старі лише
   наперед — не більше ніж на 3 дні публікації («Старих на день» × 3 Карток, що ще не пішли на
   Шафу), решта чекає, поки черга зменшиться: так не витрачається весь бюджет одразу.
5. **Якщо на диску C: мало місця** (фото старих постів копіюються в теку програми): *до*
   встановлення (крок 3) у чорному вікні виконай `setx SHAFA_DATA_DIR "D:\shafa"` і закрий вікно,
   потім встановлюй. Тоді всі шляхи `%LOCALAPPDATA%\shafa` у цій інструкції читай як `D:\shafa`
   (наприклад, `D:\shafa\app\python\python.exe`).

### 5б. Сайт Viktoria Shoes (нові пари з бота)
Пост, який бот опублікував у канал, програма сама заводить на сайт: поля, потім фото по одному.
Ручні пости в канал і старі пости на сайт не йдуть. Канал на сайт ніколи не чекає.
1. **Ключ сайту вписуєш ти** (не вона): Win+R → `%LOCALAPPDATA%\shafa\app\python\python.exe -m shafa setup`
   → на всіх питаннях Enter (лишає старе), на «Ключ сайту…» — встав ключ → Enter. Ключ лягає в
   `%LOCALAPPDATA%\shafa\.env` (лише для її користувача Windows); ніде на екрані не показується.
2. «Вийти» на екрані й знову ярлик «Шафа-помічник» (бот перечитає ключ).
3. Вкладка **«Налаштування»** → **«Відправляти на сайт нові пари з бота»** — типово **вимкнено**.
   Увімкни **разом із нею** перед одним справжнім новим постом → «Зберегти».
4. Вона публікує пост через бота. → Через хвилину-дві пара з'являється в адмінці сайту (з ціною,
   розміром і підкатегорією — одразу видима; інакше — прихована, відкриває вона).
   Журнал: `%LOCALAPPDATA%\shafa\bot-run.log`, рядки «Сайт: пост N — …».
5. Усе гаразд → **лиши увімкненим**.
- Немає інтернету — пари чекають у черзі й доходять пізніше, навіть після перезапуску ноутбука.
- Сайт не прийняв ключ (401) або інтеграцію вимкнено (404) → тобі одне повідомлення в боті, черга
  стоїть. Новий ключ (крок 1) → «Вийти» → ярлик.
- Пару не прийнято (400/409) → тобі й їй повідомлення з номером поста; таку пару вона додає в адмінці руками.
- Вимкнула перемикач — нові пости в чергу не стають, а ті, що вже в черзі, чекають, доки знову ввімкне.

### 6. AnyDesk (для допомоги віддалено)
1. anydesk.com → Download → запусти. → Видно її номер AnyDesk — запиши.
2. Доступ без підтвердження (пароль) — **лише якщо вона згодна**.

## Потім: оновлення (через AnyDesk)
1. На Mac: `.venv/bin/python ops/build_windows.py build` → новий zip.
2. Скопіюй zip на її ноутбук, «Видобути все», двічі клацни **«Встановити»**.
   → Програма сама закриється, стара версія заміниться. **Налаштування, база, вхід на Шафу — лишаються.**
   → Якщо «Програма ще працює» — на екрані «Вийти» (і дочекайся, поки робот допише товар), потім знову «Встановити».

## Якщо щось не так
- Екран не відкривається → журнал: `%LOCALAPPDATA%\shafa\app.log` (Win+R → вставити шлях → Enter).
- Бот: панель на екрані пише причину («зупинився: …»). Журнал бота — `%LOCALAPPDATA%\shafa\bot-run.log`.
- Змінити ключ чи токен → двічі клацни «Встановити» з тієї ж теки → майстер не почнеться, тоді
  Win+R → `%LOCALAPPDATA%\shafa\app\python\python.exe -m shafa setup` → Enter лишає старе, вставлене — замінює.
- Майстер ніяк не приймає ключ → запасний шлях, Блокнот: Win+R → `notepad %LOCALAPPDATA%\shafa\.env`
  (дані в іншій теці, напр. `D:\shafa` — `notepad D:\shafa\.env`) → у рядку `ANTHROPIC_API_KEY=` /
  `TELEGRAM_BOT_TOKEN=` / `SITE_INTEGRATION_KEY=` встав значення після `=` (Ctrl+V тут працює), без
  пробілів → Ctrl+S → закрий; на екрані «Вийти» і знову ярлик.
- Бот: «У каналу немає групи для коментарів», хоча щойно прив'язала → Telegram оновлює це кілька хвилин:
  зачекай 5 хв і запусти ще раз.
- Вікно входу на Шафу не закривається хрестиком → на екрані кнопка «Я увійшов — закрити вікно»
  (за 15 хв вікно закривається саме).
